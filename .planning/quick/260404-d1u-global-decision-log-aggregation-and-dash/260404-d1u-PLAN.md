   - Same structure as `discoverTokenLogs` but searches for `decision-log.jsonl` instead of `token-log.jsonl`

   - Same pattern as `loadCache` but reads from `DECISION_CACHE_PATH`

   - Same structure as `processFile` but:
     - Does NOT compute opus_baseline_usd (decisions have no token cost)

     - Uses `buildDecisionDedupKey` for dedup
     - Parses each JSONL line, skips malformed

   - Load decision dedup set and decision cache

10. Update the standalone mode console.log and hook mode additionalContext to mention decision counts


2. Add `computeDecisionMetrics(decisionRecords)` function that does a single-pass accumulation:
   - `totalDecisions`: count of all records
   - `dismissCount`: count where `outcome === 'dismissed'` OR `dismissed_at !== null`
   - `dismissRate`: `(dismissCount / totalDecisions * 100).toFixed(1)` or '0.0'
   - `blocksByCategory`: Map of `review_block_category` (non-null only) to count. Include scan blocks where `scan_verdict === 'BLOCK'` under category 'scan-block' if review_block_category is null.
   - `blockRate`: percentage of Stop events (event_type==='Stop') where review_verdict==='BLOCK' out of total Stop events
   - `scanBlockRate`: percentage of PostToolUse events where scan_verdict==='BLOCK' out of total PostToolUse events with scan_triggered===true
   - `byProject`: Map of project name to `{ total, blocks, dismissals, scans_triggered, scan_blocks }`
   - `byTaskType`: Map of task_type to `{ total, blocks }`
   - Return object with all above fields

3. Build the Decision Intelligence HTML section. Insert it AFTER the Fallback Events section and BEFORE the Task Type Distribution section. Structure:

   a. **Summary cards row** (4 cards, same .summary-cards/.card classes):
      - Total Decisions (totalDecisions)
      - Dismiss Rate (dismissRate + %)
      - Review Block Rate (blockRate + %, color: var(--text-danger) if > 0)
      - Scan Block Rate (scanBlockRate + %, color: var(--text-warning) if > 0)

   b. **Block Rate by Category table** (same .data-table class):
      - Columns: Category, Blocks, % of All Blocks
      - Rows from blocksByCategory, sorted by count desc
      - If empty: italic "No block events recorded."

   c. **Per-Project Decision Counts table** (same .data-table class):
      - Columns: Project, Total Events, Review Blocks, Scan Blocks, Dismissals
      - Rows from byProject, sorted by total desc
      - If empty: italic "No decision data."

4. Add `decisionMetrics` to the DASHBOARD_DATA JSON embedded in the HTML (alongside existing keys) so client-side JS can access it if needed in future.

5. Do NOT modify any existing panels, charts, or metrics. The new section is purely additive.
