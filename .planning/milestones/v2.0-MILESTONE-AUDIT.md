## Integration Issues Found & Resolved

### FIXED: Token logging pipeline break (codex-handoff.js → token-logger)

**Problem:** Phase 13 gap fix moved `[CODEX_RESULT]` markers from `console.log` (stdout) to `console.error` (stderr) to prevent JSON parsing corruption. However, `codex-token-logger.js` reads `data.tool_result` which only contains stdout, so execution events from the Codex pipeline were invisible to all downstream reporting.

**Fix:** Replaced stderr markers with direct `fs.appendFileSync` to `token-log.jsonl` inside `codex-handoff.js`, matching the pattern established in `minimax-post-scan.js`, `codex-review-gate.js`, and `codex-multi-round-reviewer.js`. The MiniMax fallback path also includes `fallback_from: 'codex-cli'` for the Fallback Events dashboard panel.
