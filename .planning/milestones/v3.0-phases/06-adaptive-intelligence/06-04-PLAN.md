**analyze.md** — implements /seraphim:analyze (D-08: on-demand deep analysis).

Structure mirrors other commands: brief description header, then a ```javascript block that Claude executes inline.

The script must:
1. Resolve projectRoot from process.env.PROJECT_ROOT || process.cwd()
2. Call aggregateDecisions(projectRoot) — if result is empty array, print "No pipeline data yet. Run /seraphim:run first." and exit
3. Call groupIntoRuns(records) to get runs array
4. Call computeRejectionRates(records) to get rejection metrics
5. Call computeProfileMetrics(runs) to get profile metrics
6. Load ALL records (including recommendation types) from decisions.jsonl via fs.readFileSync — this is needed for deduplication in generateRecommendations
7. Call generateRecommendations(rejectionRates, allRecords) — also pass profileMetrics entries through generateRecommendations by iterating RULES against profileMetrics for the low-crucible-pass-rate rule
8. Call appendRecommendations(projectRoot, newRecs) to persist any new ones
9. Call writeDashboard({rejectionRates, profileMetrics, recommendations: allRecs.filter(r=>r.type==='recommendation'), generatedAt: new Date().toISOString()}) to regenerate dashboard
10. Print the bordered terminal display for each recommendation (use the box format from RESEARCH.md)
11. If no recommendations: print "Seraphim Analysis — No recommendations at this time. {N} pipeline runs analyzed."
12. Print "Dashboard updated: ~/.claude/plugins/seraphim/dashboard/seraphim.html"

Confidence label meaning note: LOW-confidence recommendations must include the label "Informational only" after the confidence tag per D-02/D-03.

**recommendations.md** — implements /seraphim:recommendations (show pending + history + dismiss).

The command accepts an optional subcommand argument: `dismiss <rec_id>`.

Script structure:
1. Parse $ARGUMENTS (Claude command argument string) — if it starts with "dismiss ", extract rec_id
2. If dismiss mode: call appendRejection(projectRoot, rec_id, "User dismissed via /seraphim:recommendations dismiss") — print "Recommendation {rec_id} dismissed." and exit
3. Otherwise (display mode):
   - Load all records from decisions.jsonl
   - Filter to recommendation records: type=recommendation
   - Filter to response records: type=recommendation_response
   - Separate pending (status=pending, no matching response with response!='pending') from resolved
   - Print "=== Pending Recommendations ===" section with box format; if none, print "No pending recommendations."
   - Print "=== History ===" table: rec_id | phase | model | confidence | status | timestamp (show last 10)
4. Always print "Run /seraphim:analyze to refresh recommendations."
