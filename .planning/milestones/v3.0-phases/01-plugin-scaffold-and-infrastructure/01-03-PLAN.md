**File 3: ~/.claude/plugins/seraphim/hooks/session-start.js**

Node.js script following the verified superpowers 5.0.7 pattern. Must implement:

1. 10-second timeout guard: `setTimeout(() => { process.stdout.write('{}'); process.exit(0); }, 10000)`
2. Read stdin as UTF-8, accumulate chunks, parse JSON on 'end' event
3. Extract `data.cwd` from parsed input (fallback to `process.cwd()`)
4. Check if `.seraphim/config.json` exists at that cwd. If not, output `{}` and exit (not a Seraphim project)
5. If config exists, read and parse it. Build a markdown status string containing:
   - Profile name (from config.profile, default 'moderate')
   - Opus status (enabled/disabled based on config.opus_enabled)
   - Project type (from config.project_type, default 'code')
   - Max loops (from config.max_loops, default 2)
   - Any active overrides (iterate config.overrides entries)
   - A reminder line: "Use `/seraphim:` commands to run the pipeline."
6. Output: `JSON.stringify({ hookSpecificOutput: { hookEventName: 'SessionStart', additionalContext: contextString } })`
7. Wrap everything in try/catch. On any error, output `{}` and exit cleanly. Never throw.

Use `'use strict'` at top. Only Node.js built-ins (fs, path). No external packages.
