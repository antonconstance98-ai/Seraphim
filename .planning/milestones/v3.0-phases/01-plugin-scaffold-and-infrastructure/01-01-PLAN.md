Write `~/.claude/plugins/seraphim/.claude-plugin/plugin.json` with exactly:
```json
{
  "name": "seraphim",
  "version": "3.0.0",
  "description": "Six-phase multi-model creative pipeline. Discover, Envision, Judge, Architect, Forge, Crucible.",
  "author": {
    "name": "Dragos"
  }
}
```

CRITICAL: The manifest MUST be at `.claude-plugin/plugin.json` inside the plugin root, NOT at the plugin root level. Placing it at the root causes silent failure where the plugin appears enabled but no /seraphim: commands register (Pitfall 1 from research).

Do NOT declare hooks in plugin.json. Hooks are auto-discovered from hooks/hooks.json (Pitfall 2 from research).
