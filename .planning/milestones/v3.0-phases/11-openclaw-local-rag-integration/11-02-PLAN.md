  <files>~/.claude/plugins/seraphim/tools/query-knowledge.js</files>
  <action>
Create `~/.claude/plugins/seraphim/tools/query-knowledge.js` as a standalone Node.js CLI script (not a module — it is invoked with `node query-knowledge.js ...`).

**CLI interface:**
```
node query-knowledge.js --project <projectRoot> --query <queryText> [--threshold 0.75] [--max-tokens 1500]
```

**Argument parsing:** Use `process.argv` directly — no external arg-parsing library.
- `--project`: path to project root (required). Resolve to absolute path.
- `--query`: query text string (required). May be multi-word — collect all tokens after `--query` until next `--` flag.
- `--threshold`: float, default 0.75
- `--max-tokens`: integer, default 1500

**Behavior:**
1. If `--project` or `--query` is missing, exit 0 with empty output (silent — caller treats empty output as "no context available")
2. Check whether `{projectRoot}/.seraphim/rag/knowledge.sqlite` exists. If not, exit 0 with empty output (index not built yet — not an error)
3. Call `queryKnowledge(projectRoot, queryText, { threshold, maxTokens })` from `require('../lib/rag-indexer')`
4. If result.context is empty string, exit 0 with empty output
5. Print result.context to stdout. Exit 0.
6. On any thrown error: print nothing to stdout, print error to stderr, exit 0 (per D-09: phases must never fail because RAG is unavailable)

The `2>/dev/null` suppression in run.md callers means stderr is discarded — printing to stderr is safe for debug information.

**rag-post-phase.js:**

Create `~/.claude/plugins/seraphim/hooks/rag-post-phase.js` following the exact stdin/stdout event pattern used by existing hooks (token-logger.js, session-start.js).

The hook fires after a phase write completes. It must:
1. Read JSON event from stdin (standard hook input)
2. Determine `projectRoot`: walk up from `event.cwd` (or `process.cwd()`) looking for `.seraphim/config.json` — same logic as run.md Step 2
3. If no projectRoot found, immediately exit 0 with `{ continue: true }`
4. Fire-and-forget re-index: spawn `node {PLUGIN_ROOT}/lib/rag-indexer.js --reindex {projectRoot}` as a detached child process using `spawn(..., { detached: true, stdio: 'ignore' })` then call `.unref()` so the hook process can exit without waiting
   - ALTERNATIVELY: if rag-indexer.js exports `indexProject` (it does), just call it in a separate Promise that is NOT awaited — but spawning a subprocess is cleaner for fire-and-forget since it doesn't risk keeping the Node.js event loop alive
   - Use spawn pattern: `const { spawn } = require('child_process'); const child = spawn('node', [path.join(PLUGIN_ROOT, 'lib', 'rag-indexer.js'), '--reindex', projectRoot], { detached: true, stdio: 'ignore' }); child.unref();`
5. Immediately respond: `process.stdout.write(JSON.stringify({ continue: true }) + '\n')` and `process.exit(0)`

Note: rag-indexer.js must support a `--reindex <projectRoot>` CLI invocation. Add this at the bottom of rag-indexer.js (if block on `require.main === module`):
```javascript
if (require.main === module) {
  const args = process.argv.slice(2);
  const reindexIdx = args.indexOf('--reindex');
  if (reindexIdx !== -1) {
    const projectRoot = args[reindexIdx + 1];
    indexProject(projectRoot, {}).then(r => {
      process.stderr.write(`[rag] reindex complete: ${JSON.stringify(r)}\n`);
      process.exit(0);
    }).catch(e => {
      process.stderr.write(`[rag] reindex error: ${e.message}\n`);
      process.exit(0); // never fail-hard from background reindex
    });
  }
}
```
Add this CLI block to `~/.claude/plugins/seraphim/lib/rag-indexer.js` as well.
