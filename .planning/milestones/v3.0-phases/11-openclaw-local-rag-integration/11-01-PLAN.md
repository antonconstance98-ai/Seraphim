Four-table schema (OpenClaw pattern, from RESEARCH.md):
```sql
CREATE TABLE IF NOT EXISTS files (
  path TEXT PRIMARY KEY, mtime REAL, size INTEGER, hash TEXT
);
CREATE TABLE IF NOT EXISTS chunks (
  rowid INTEGER PRIMARY KEY AUTOINCREMENT,
  path TEXT, start_line INTEGER, end_line INTEGER,
  text TEXT,
  embedding TEXT  -- JSON float array, fallback path
);
CREATE VIRTUAL TABLE IF NOT EXISTS chunks_vec USING vec0(embedding float[384]);
CREATE VIRTUAL TABLE IF NOT EXISTS chunks_fts USING fts5(text, content=chunks, content_rowid=rowid);
```

Then create `~/.claude/plugins/seraphim/lib/rag-indexer.js` as a CommonJS module exporting: `createDb`, `indexProject`, `queryKnowledge`, `isStale`.

**createDb(dbPath):**
- Open better-sqlite3 database at dbPath
- Attempt `sqliteVec.load(db)` in a try/catch. On success, set `db._vecEnabled = true`. On failure, set `db._vecEnabled = false` and log to stderr: `[rag] sqlite-vec not loaded — using JS fallback`
- Create four tables with the exact schema from RESEARCH.md (files, chunks, chunks_vec, chunks_fts)
- If `_vecEnabled` is false, skip `CREATE VIRTUAL TABLE chunks_vec`
- Return the `db` object

**isStale(db, filePath):**
- Per Pattern 1 in RESEARCH.md: query `files` table for mtime and hash
- If not found → return true
- If stat mtime matches row.mtime → return false (unchanged)
- Otherwise compute SHA-256 of file contents → compare with row.hash → return boolean

**chunkText(text, filePath):**
- For `.jsonl` files: split by newline, each non-empty line is one chunk. Skip lines where parsed JSON has `type === "meta"` or missing `phase` field (per Pitfall 3)
- For `.md` files: split on `\n## ` and `\n### ` boundaries. Do NOT split inside ``` fences or lines starting with `<!--`. Minimum chunk length: 50 chars. Maximum: 1000 chars (truncate with `...` suffix)
- For `.js`, `.ts`, `.py`: split on function/class declarations (`^(export )?(async )?function `, `^class `, `^def `). Fallback: 40-line sliding window with 10-line overlap
- For `.json` files: whole document as one chunk
- Returns array of `{ text, startLine, endLine }`

**indexProject(projectRoot, options = {}):**
- Determine dbPath: `path.join(projectRoot, '.seraphim', 'rag', 'knowledge.sqlite')`
- Create parent dir if not exists
- Call `createDb(dbPath)` to get `db`
- Scan file paths from these patterns (per D-04 / RESEARCH.md indexing table):
  - `.seraphim/phases/*/vision.md`, `judgment.md`, `blueprint.md`, `crucible.md`, `forge-log.md`
  - `.seraphim/phases/*/discovery/*.md`
  - `.seraphim/decisions.jsonl`
  - `.planning/phases/*-CONTEXT.md`
  - `.seraphim/config.json`
  - `src/**/*.{js,ts,py}`, `lib/**/*.{js,ts}` (cap at `options.maxSourceFiles || 200`)
- Exclude: `node_modules`, `.git`, `*.sqlite`, `*.db`, `.seraphim/rag/`, files > 500KB, `.planning/.hook-state/`
- For each file: call `isStale(db, filePath)` — skip if not stale
- For stale/new files: chunk with `chunkText`, embed each chunk with `embed()` (see embedder singleton)
- Insert into `chunks` table (text, path, start_line, end_line, embedding as JSON.stringify(floatArray))
- If `db._vecEnabled`: also insert binary embedding into `chunks_vec` using `Buffer.from(new Float32Array(embedding).buffer)`
- Insert/update `files` table with new mtime, size, hash
- FTS: `INSERT INTO chunks_fts(rowid, text) VALUES (?, ?)` for each new chunk rowid
- Returns `{ indexed: N, skipped: M, errors: [] }`

**queryKnowledge(projectRoot, queryText, options = {}):**
- threshold default: 0.75 (cosine similarity). maxTokens default: 1500.
- Open db at `path.join(projectRoot, '.seraphim', 'rag', 'knowledge.sqlite')`. If file does not exist, return `{ context: '', chunks: [] }`
- Embed queryText → queryEmbedding (384 floats)
- Hybrid search (Pattern 2 from RESEARCH.md):
  - If `db._vecEnabled`: run vec query with `vec_distance_cosine(v.embedding, ?)`, convert distance to similarity = `1 - distance`, filter >= threshold. Limit k*2 = 10
  - Always run FTS query: `WHERE chunks_fts MATCH ?` with queryText, limit 10
  - Merge by rowid, deduplicate. Weighted score: `0.7 * semantic_score + 0.3 * keyword_score`
  - If `!db._vecEnabled`: compute cosine similarity in JS against stored JSON embeddings from chunks table, filter >= threshold
- Rank merged results descending by score. Take top 5.
- Apply token budget: accumulate `chunk.text.length / 4` tokens, stop when budget exceeded
- Return `{ context: formattedString, chunks: rankedArray }`
- Format: each chunk as `### [{path}]\n{text}\n`

'use strict';
try {
  // Monkey-patch sqlite-vec to simulate load failure
  const Module = require('module');
  const origLoad = Module._load;
  Module._load = function(req, ...args) {
    if (req === 'sqlite-vec') {
      return { load: () => { throw new Error('simulated sqlite-vec load failure'); } };
    }
    return origLoad.call(this, req, ...args);
  };

  const { createDb } = require('../lib/rag-indexer');
  const os = require('os');
  const path = require('path');
  const fs = require('fs');
  const tmp = fs.mkdtempSync(path.join(os.tmpdir(), 'rag-fallback-'));

  const dbPath = path.join(tmp, '.seraphim', 'rag', 'knowledge.sqlite');

  console.assert(db._vecEnabled === false, 'db._vecEnabled should be false when sqlite-vec fails to load');
  console.log('PASS: test-rag-fallback');
