**run.md changes:**

Read `~/.claude/plugins/seraphim/commands/run.md`. Insert a new sub-step **6b-RAG** between the existing Step 6a (loop cap check) and Step 6b (invoke the phase command). The new step injects RAG context before each phase dispatches.

Insert after the existing "### 6a — Check loop caps" section and before "### 6b — Invoke the phase command":

~~~markdown
### 6b-RAG — Query project knowledge and inject context (per D-09)

Before invoking the phase command, query the local RAG index for relevant context.
This step is silent — if no index exists or the query returns empty, proceed without injection.

First, read the RAG config:

```bash
PLUGIN_ROOT="$HOME/.claude/plugins/seraphim"
RAG_ENABLED=$(node -e "
  const cfg = require('${PLUGIN_ROOT}/lib/config').read('${PROJECT_ROOT}');
  console.log((cfg.rag && cfg.rag.enabled !== false) ? 'true' : 'false');
" 2>/dev/null)
```

If `RAG_ENABLED` is `false`, skip this step entirely.

Define a phase-appropriate query string for each phase:
- `discover` → "external research codebase analysis discovery"
- `envision` → "creative approaches vision possibilities"
- `judge` → "evaluation criteria decision patterns quality signals"
- `architect` → "blueprint implementation plan task breakdown prior architecture"
- `forge` → "implementation code patterns conventions completed work"
- `crucible` → "testing verification quality gate pass criteria"

Query the index:

```bash
PHASE_QUERY="{phase-appropriate query string for current phase}"
RAG_CONTEXT=$(node "$PLUGIN_ROOT/tools/query-knowledge.js" \
  --project "$PROJECT_ROOT" \
  --query "$PHASE_QUERY" \
  --threshold 0.75 \
  --max-tokens 1500 2>/dev/null)
```

If `RAG_CONTEXT` is non-empty, prepend it to the phase prompt as a context block before executing Step 6b.
The prepended block format is:

    ## Prior Project Knowledge
    {RAG_CONTEXT}
    ---

This context block is injected silently — it does not change the phase command's logic, only
enriches the context it receives. If `RAG_CONTEXT` is empty, no block is prepended.
~~~

Preserve all existing content in run.md exactly. Only insert the new 6b-RAG sub-step in the correct location.
