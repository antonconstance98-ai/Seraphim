  <action>
    Create `~/.claude/hooks/migrate-opus-pricing.js` -- standalone idempotent migration script (D-09).

    **Architecture decision:** Per-project `token-log.jsonl` does NOT contain `opus_baseline_usd` -- the aggregator adds it during merge. Migration only rewrites `~/.claude/dashboard/global.jsonl`.

    **Script requirements:**

    1. **Read** `~/.claude/dashboard/global.jsonl` line by line into an array.

    2. **Transform** each line:
       - Blank lines: preserve as-is (push unchanged).
       - Non-JSON lines: preserve as-is (push unchanged). Increment `malformed` counter.
       - Valid JSON with `tokens` field: recalculate `opus_baseline_usd` using formula:
         `(tokens.input * 5.00 + tokens.cached_input * 1.25 + tokens.output * 25.00) / 1_000_000`
         No rounding (matches `computeOpusCost` behavior). Missing token fields default to 0.
         Push `JSON.stringify(record)`.
       - Valid JSON without `tokens`: preserve via `JSON.stringify(record)`.

    3. **Write atomically**: join with `\n`, write to `.tmp.<pid>`, `fs.renameSync` over original.

    4. **Regenerate dashboard**: `require('./codex-dashboard-generator').generateDashboard(DASHBOARD_DIR)`.
       Wrap in try/catch -- warn on failure but don't abort.

    5. **Print summary**: records processed, updated, malformed, old vs new opus_baseline totals, dashboard status.

    **Concurrency note:** The aggregator appends to global.jsonl via `fs.appendFileSync` on SessionStart. This is a single-user workstation. The migration runs once interactively (not as a hook). Risk of concurrent write is negligible. If a record is lost during the atomic rename, the next aggregation run will re-discover it from source token-log.jsonl files (dedup is content-independent: `session_id|timestamp`).

    **Idempotency:** The script deterministically recomputes `opus_baseline_usd` from stored token counts. Running it N times on the same input produces semantically identical output. Note: JSON.stringify may normalize key ordering vs the original file, but all field VALUES are preserved.

    **After creating, run it:**
    ```bash
    node ~/.claude/hooks/migrate-opus-pricing.js
    ```
