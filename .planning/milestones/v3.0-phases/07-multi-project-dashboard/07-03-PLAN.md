**components/MarkdownRenderer.tsx** ('use client'):
```typescript
'use client';
import { useEffect, useState } from 'react';

interface Props { content: string; }

export function MarkdownRenderer({ content }: Props) {
  const [html, setHtml] = useState('');
  useEffect(() => {
    import('marked').then(({ marked }) => {
      setHtml(marked.parse(content) as string);
    });
  }, [content]);
  return (
    <div
      className="prose prose-invert max-w-none text-sm"
      dangerouslySetInnerHTML={{ __html: html }}
    />
  );
}
```
Note: `dangerouslySetInnerHTML` is acceptable here — content comes from the user's own local .md files, not external input.

```typescript
interface Props { params: Promise<{ name: string }> }
```
Note: In Next.js 15+, `params` is async — must `await params` before accessing `.name` (per Next.js async patterns skill).

Steps:
1. `const { name } = await params`
2. Decode: `const projectName = decodeURIComponent(name)`
3. Fetch in parallel: `const [phaseStates, decisions] = await Promise.all([getPhaseStates(projectName), getProjectDecisions(projectName)])`
4. Group decisions into pipeline runs (a new run starts when phase === 'discover' after at least one prior record).

Render sections:
- **Header**: project name, back link to `/`.
- **Phase Roadmap**: `<PhaseRoadmap phaseStates={phaseStates} />`.
- **Pipeline Run History**: table of runs — each run shows run number, date, total cost, outcome summary (pass/fail per phase), total tokens.
- **Human Tasks**: scan decisions for `outcome === 'loop_trigger'` or `quality_signals.loop_trigger_reason !== null` — list these as "Needs human review" items. If none: show "No pending human tasks."
- **AI Activity**: list recent decisions (last 20) with phase, model, cost, outcome, latency.

If project not found in DB (phaseStates and decisions both empty): show "Project not found. It may not have pushed any data yet." with back link.
