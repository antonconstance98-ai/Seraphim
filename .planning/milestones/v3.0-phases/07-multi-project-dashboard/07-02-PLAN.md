<!-- Neon Postgres DB schema (from RESEARCH.md) -->
```sql
CREATE TABLE projects (
  name VARCHAR(255) PRIMARY KEY,
  root_path TEXT,
  profile VARCHAR(50),
  last_pushed_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE decisions (
  id SERIAL PRIMARY KEY,
  project_name VARCHAR(255) REFERENCES projects(name),
  timestamp TIMESTAMPTZ,
  phase VARCHAR(50),
  model VARCHAR(100),
  profile VARCHAR(50),
  tokens_in INTEGER,
  tokens_out INTEGER,
  cost_usd NUMERIC(10,6),
  latency_ms INTEGER,
  outcome VARCHAR(50),
  retry_count INTEGER DEFAULT 0,
  loop_count INTEGER DEFAULT 0,
  quality_signals JSONB
);

CREATE TABLE phase_states (
  id SERIAL PRIMARY KEY,
  project_name VARCHAR(255) REFERENCES projects(name),
  phase_id VARCHAR(50),
  completed BOOLEAN DEFAULT FALSE,
  completed_at TIMESTAMPTZ,
  loops JSONB,
  retries JSONB,
  updated_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE(project_name, phase_id)
);
```

**Step 6 — lib/db.ts:**
CRITICAL: Never call `neon()` at module top-level — it crashes `next build` when DATABASE_URL is unset.
```typescript
import { neon } from '@neondatabase/serverless';
import type { NeonQueryFunction } from '@neondatabase/serverless';

let _sql: NeonQueryFunction<false, false> | null = null;

export function getSql(): NeonQueryFunction<false, false> {
  if (!_sql) {
    _sql = neon(process.env.DATABASE_URL!);
  }
  return _sql;
}
```

**app/api/ingest/route.ts:**
POST endpoint that receives workstation push. Steps:
1. Check `Authorization: Bearer ${process.env.DASHBOARD_SECRET}` header. If mismatch: return 401 JSON `{error: 'Unauthorized'}`.
2. Parse `req.json()` as `IngestPayload`.
3. `const sql = getSql()` (lazy — never at module scope).
4. Upsert project:
```sql
INSERT INTO projects (name, root_path, profile, last_pushed_at)
VALUES ($name, $root_path, $profile, $pushed_at)
ON CONFLICT (name) DO UPDATE
SET root_path = EXCLUDED.root_path,
    profile = EXCLUDED.profile,
    last_pushed_at = EXCLUDED.last_pushed_at
```
5. Insert decisions (if any in payload) — batch insert, skip records missing required fields:
```sql
INSERT INTO decisions (project_name, timestamp, phase, model, profile,
  tokens_in, tokens_out, cost_usd, latency_ms, outcome,
  retry_count, loop_count, quality_signals)
VALUES (...)
```
6. Upsert phase_state for `payload.phase_id`:
```sql
INSERT INTO phase_states (project_name, phase_id, completed, completed_at, loops, retries, updated_at)
VALUES (...)
ON CONFLICT (project_name, phase_id) DO UPDATE SET
  completed = EXCLUDED.completed,
  completed_at = EXCLUDED.completed_at,
  loops = EXCLUDED.loops,
  retries = EXCLUDED.retries,
  updated_at = NOW()
```
7. Return 200 JSON `{ok: true, project: payload.project_name, phase: payload.phase_id}`.
8. Wrap entire function body in try/catch: on error return 500 JSON `{error: err.message}`.

Do NOT use `export const runtime = 'edge'` here — ingest is a standard Serverless Function (needs full Node.js for DB write). Only the SSE events endpoint uses Edge Runtime (plan 04).
