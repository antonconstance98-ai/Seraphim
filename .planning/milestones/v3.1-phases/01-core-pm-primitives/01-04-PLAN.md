    **Extend `pause.md` Step 3** — After the existing state write (`state.paused = true`, etc.), add PM context block per D-07:

    Add these lines to the existing `node -e` script in Step 3, BEFORE the `ps.writeState()` call:

    ```javascript
    // PM context block (D-07) — survives session restart
    const roadmap = require('${PLUGIN_ROOT}/lib/roadmap');
    const rm = roadmap.readRoadmap('${PROJECT_ROOT}');
    // Find the first in-progress feature (if any)
    let pmBlock = null;
    for (const ms of rm.milestones) {
      for (const f of ms.features) {
        if (f.status === 'in-progress') {
          pmBlock = {
            feature_id: f.id,
            milestone_version: ms.version,
            progress: {
              phase: '${CURRENT_PIPELINE_PHASE}',
              status: 'paused'
            }
          };
          break;
        }
      }
      if (pmBlock) break;
    }
    state.pm = pmBlock; // null if no active feature — backward compat
    ```

    Keep ALL existing pause.md content intact. Only extend the Step 3 node script.

    Frontmatter:
    ```yaml
    ---
    description: "Archive a completed milestone — freezes to milestones/ and computes cost"
    argument-hint: "<milestone-version>"
    allowed-tools: ["Read", "Bash"]
    ---
    ```

    **Step 1 — Parse arguments**: Extract milestone version (e.g., `v3.1`). If missing, abort with usage.

    **Step 2 — Resolve project root** (walk-up pattern).

    **Step 3 — Archive milestone**

    Run a `node -e` script that:
    1. Requires roadmap.js
    2. Reads roadmap — finds milestone by version
    3. If not found, print "Milestone {version} not found." and exit
    4. Computes milestone progress — if not 100% complete, print warning: "Milestone {version} is {percent}% complete. Are you sure? Pass --force to archive anyway." Exit unless `--force` flag is detected in arguments.
    5. Reads `.seraphim/decisions.jsonl` line by line. For each line, parse JSON. Collect entries where `feature_id` is in the milestone's feature IDs. Sum `cost_usd` per feature and total.
    6. Creates archive object per RESEARCH.md archive schema:
       ```json
       {
         "version": "v3.1",
         "name": "Seraphim Project Management",
         "archived_at": "ISO timestamp",
         "completion_percent": 100,
         "features": [/* snapshot */],
         "cost_usd": 4.23,
         "cost_breakdown": [
           { "feature_id": "feat-001", "cost_usd": 2.10 }
         ]
       }
       ```
    7. Creates `.seraphim/milestones/` directory if missing
    8. Writes archive to `.seraphim/milestones/{version}.json` using atomic temp+rename
    9. Removes the milestone from roadmap.json's milestones array
    10. Writes updated roadmap via `writeRoadmap()`
