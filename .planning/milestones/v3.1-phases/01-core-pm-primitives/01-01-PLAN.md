  <action>
    **Create `~/.claude/plugins/seraphim/lib/roadmap.js`** with these exports:

    1. `readRoadmap(projectRoot)` — reads `.seraphim/roadmap.json`. If file missing, returns `{ milestones: [] }` (per D-08). Uses `fs.readFileSync`.

    2. `writeRoadmap(projectRoot, data)` — writes roadmap.json using atomic temp-file rename pattern (write to `roadmap.json.tmp`, then `fs.renameSync` to `roadmap.json`). Creates `.seraphim/` dir if missing.

    3. `findFeature(roadmap, ref)` — accepts either `feat-NNN` ID or slug string (per D-01). Iterates all milestones and features. Returns `{ feature, milestone }` or `null`.

    4. `nextFeatureId(roadmap)` — scans all features across all milestones, finds the highest numeric suffix from `feat-NNN` IDs, returns `feat-{max+1}` zero-padded to 3 digits. If no features exist, returns `feat-001`.

    5. `countWip(roadmap)` — counts features with `status === 'in-progress'` across all milestones. Returns integer.

    6. `milestoneProgress(milestone)` — returns `{ complete: N, total: M, percent: Math.round(N/M*100) }` from feature statuses. If total is 0, percent is 0.

    All functions use `'use strict'` and synchronous fs calls matching the phase-state.js pattern.

    **Extend `~/.claude/plugins/seraphim/lib/config.js`** — add `max_wip: 2` to `CONFIG_DEFAULTS` object (per D-06). Place it after the `max_loops` field. No other changes.

    **Extend `~/.claude/plugins/seraphim/lib/decisions-logger.js`** — add `feature_id = null` parameter to `buildRecord()` destructured args (per D-09). Add `feature_id` field to the returned object, placed after `loop_count`. No other changes to the function. Existing callers that don't pass `feature_id` get `null` automatically.
  </action>
