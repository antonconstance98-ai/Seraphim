Create `lib/research-tracker.js` following the `requirements.js` atomic read/write pattern exactly (per D-04).

Functions to export:
- `readResearch(projectRoot)` — reads `.seraphim/research.json`, returns `{ items: {} }` on missing/error
- `writeResearch(projectRoot, data)` — atomic tmp+rename write to `.seraphim/research.json`, creates `.seraphim/` dir if missing
- `nextResearchId(data)` — scans `data.items` keys matching `RSRCH-NNN`, returns next zero-padded ID (e.g., `RSRCH-001`)
- `addResearch(projectRoot, { topic, questions, constraints, categories })` — reads current data, generates next ID, writes item with `status: "scoped"`, `created_at: new Date().toISOString()`, `results: null`, `completed_at: null`. Returns the new item.
- `updateResearch(projectRoot, id, updates)` — reads, merges updates into `data.items[id]`, writes. Returns updated item or null if ID not found.
- `getScopedItems(projectRoot)` — reads and returns array of items where `status === "scoped"`

Use `'use strict'` at top. Module.exports all functions.

Research item schema (per D-04):
```javascript
{
  id: 'RSRCH-001',
  topic: 'string',
  status: 'scoped' | 'running' | 'complete' | 'abandoned',
  scope: { questions: [], constraints: [], categories: [] },
  results: null | 'string',
  created_at: 'ISO',
  completed_at: null | 'ISO'
}
```
