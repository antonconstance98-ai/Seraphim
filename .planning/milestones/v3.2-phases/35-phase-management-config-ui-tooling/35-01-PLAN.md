4. `insertPhase(projectRoot, afterPhase, {title, goal, depends_on, requirements})` — inserts a decimal-numbered phase (e.g., 35.1) after `afterPhase`. Section heading becomes `### Phase 35.1: Title`. Directory is `35.1-slug/`. Adds row to Progress Table at correct position.

5. `removePhase(projectRoot, phaseNumber)` — removes phase section from ROADMAP.md ONLY if phase has no completed plans (check Progress Table status). Removes Progress Table row. Parse section boundaries using `/^### Phase [\d.]+/` regex. End of a phase section = next `### Phase` or the `---` separator before Progress Table. Per Pitfall 1 from RESEARCH.md, never regex-replace within section bodies — only match at line start.

Slug generation: lowercase title, replace spaces/special chars with hyphens, truncate to 40 chars.
