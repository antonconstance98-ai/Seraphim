**Step 2 — Define pipeline sequence (per D-33).**
The new pipeline sequence is:
```
PHASES = ['discover', 'envision', 'judge-vision', 'architect', 'judge-architecture', 'forge', 'crucible']
```

Note: `judge-vision` and `judge-architecture` are the same command (`judge.md`) invoked with different `--mode` flags. The PHASES array uses descriptive names for state tracking; the actual command dispatch maps:
- `judge-vision` → `judge {phaseId} --mode vision`
- `judge-architecture` → `judge {phaseId} --mode architecture`

**Step 3 — Autonomous lockout gate (per D-30, D-31).**
If `--autonomous` flag is present AND `--skip-human-gates` is NOT present:

a) Check if `.seraphim/phases/{phaseId}/vision.md` exists
b) If exists, check for Judge-approved marker: `PHASE_COMPLETE phase="judge" mode="vision"`
c) If either check fails, refuse with EXACT message (per D-30):
   "Autonomous mode blocked. Discover and Envision need human input — without it you get a pure AI project. Use --skip-human-gates if you really want that."

If `--skip-human-gates` IS present:
- Print loud warning: "WARNING: Skipping human gates. This will produce a pure AI project with no human creative input."
- Allow autonomous mode to proceed

**Step 4 — Execute pipeline.**
For each phase in PHASES (from `--from` if specified, otherwise from beginning):

a) Check if phase already complete (via state.json) — skip if so
b) Dispatch the appropriate command:
   - `discover` → `/seraphim:discover {phaseId}`
   - `envision` → `/seraphim:envision {phaseId}`
   - `judge-vision` → `/seraphim:judge {phaseId} --mode vision`
   - `architect` → `/seraphim:architect {phaseId}`
   - `judge-architecture` → `/seraphim:judge {phaseId} --mode architecture`
   - `forge` → `/seraphim:forge {phaseId}`
   - `crucible` → `/seraphim:crucible {phaseId}` (unchanged, not in scope)

c) After `judge-architecture` completes: check for `loop_required="true"` marker (per D-35):
   - Read `.seraphim/phases/{phaseId}/blueprint.md` or the PHASE_COMPLETE marker
   - If `loop_required="true"` AND loop count < 1 (per D-35: max 1 loop):
     - Increment loop counter via `incrementLoop()`
     - Re-invoke `architect` then `judge-architecture` again
   - If loop count >= 1: proceed with whatever blueprint exists (max 1 rework)

d) After each phase: verify output exists (updated verification table below)
