- Create function `detectCodeChanges(cwd)` that:
  1. Runs `git diff HEAD --name-only` via `execSync` with `{ cwd, timeout: 5000 }` to get modified tracked files
  2. Runs `git status --porcelain` via `execSync` with `{ cwd, timeout: 5000 }` to catch untracked new files (Pitfall 2)
  3. From `git status --porcelain`, extract filenames from lines starting with `??` (untracked) — parse column 3+ as the filename
  4. Combines both lists into a single array
  5. Filters out files where `f.startsWith('.planning/') || f.endsWith('.md') || f.endsWith('.json') && f.includes('settings')` — only care about code files, not planning docs or config
  6. Returns `codeFiles.length > 0`
  7. Wraps everything in try/catch — on error (not a git repo), returns `true` (permissive: always review if git unavailable)
- If `detectCodeChanges(data.cwd)` returns `false`, `process.exit(0)` — chat-only response, skip review per D-01

**Diff collection for Codex:**
- Create function `collectDiff(cwd)` that:
  1. Runs `git diff HEAD` via `execSync` with `{ cwd, timeout: 10000, maxBuffer: 1024 * 1024 }` for tracked file diffs
  2. Runs `git diff --no-index /dev/null` for each untracked file from `git status --porcelain` (only first 3 untracked files to limit size)
  3. Concatenates all diffs
  4. Truncates to 8000 characters max (leave room in 10,000 char additionalContext limit for the verdict)
  5. Returns the truncated diff string
  6. On error, returns empty string

2. Security vulnerabilities
3. Requirements alignment (check if changes match their stated purpose)
4. Style and convention issues

Only BLOCK for significant issues. Minor style issues should ALLOW with a note.
