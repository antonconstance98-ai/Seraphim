  #### 6a2: Human-task skip (PIPE-04)

  Read the assignee attribute from the task marker. If absent, default to 'ai'.

  ```javascript
  const taskAssignee = task.assignee || 'ai';
  if (taskAssignee === 'human') {
    humanTasks.push(task);
    appendForgeLog(forgeLogPath,
      `### Task ${task.id}: ${task.name} — SKIPPED (human required)\n` +
      `<!-- SERAPHIM:FORGE_TASK id="${task.id}" status="human_required" assignee="human" -->\n\n` +
      `- **Assignee:** human\n` +
      `- **Reason:** This task requires human judgment, expertise, or action (per blueprint assignee tag).\n` +
      `- **Description:** ${task.description || '(see blueprint for full task spec)'}\n`
    );
    continue;
  }
  ```

  This skip fires BEFORE fix-mode filtering and BEFORE execution dispatch — a human task is never attempted regardless of fix mode.

  <!-- SERAPHIM:HUMAN_TASKS count="{humanTasks.length}" -->

  {if humanTasks.length === 0:}

  - **Type:** {task.type || 'unspecified'}
  - **Description:** {task.description || '(see blueprint.md for full spec)'}
