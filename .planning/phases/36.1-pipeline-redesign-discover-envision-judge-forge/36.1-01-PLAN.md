**New structure:**

**Step 1 — Parse arguments & initialize state.**
Extract phase-id from $ARGUMENTS. Read phase state via `phase-state.js readState()`. Initialize round counter = 0, accumulated_links = [].

**Step 2 — Render banner.**
Use `renderWingBanner('discover', phaseId)`.

**Step 3 — Research round loop.**
This is an indefinite loop (per D-02: no hard cap). Each iteration:

a) Construct search queries from either:
   - Round 1: broad queries derived from the phase description / user's seed
   - Round N+1: focused queries based on human's chosen direction from previous round

b) Execute web research using Perplexity MCP (`perplexity_search` or `perplexity_research` tool) + SearXNG (fetch from `http://localhost:8888/search?q=...&format=json`). Per D-01: real web research only.

c) Present findings to human in a structured format:
   - Key findings from this round
   - New interesting links found (accumulate into running list)
   - If search results were poor: auto-retry once with refined query (per D-05). If still poor after retry, surface the issue and ask human for direction.

d) Present the 3 options (per D-03):
   ```
   What next?
   1. Go deeper on a topic (specify which)
   2. New direction (describe what you want to explore)
   3. I'm armed — move to Envision
   ```

e) Human chooses. If option 1 or 2, loop continues with new queries. If option 3, exit loop.

**Step 4 — Link curation.**
Present ALL accumulated links from all rounds. Collaboratively with human, filter down to 5-7 high-importance links (per D-04). Links should be diverse: articles, Twitter threads, YouTube, podcasts, docs.

**Step 5 — Write discovery.md.**
Write to `.seraphim/phases/{phaseId}/discovery.md` (per D-06, single file replaces old `discovery/external.md` + `discovery/internal.md`). Format:

```markdown
<!-- SERAPHIM:PHASE_START phase="discover" round_count="N" -->

# Discovery: {phase title}

## Research Findings

{Summarized findings from all rounds, organized by theme}

## Curated Links

{5-7 links with title, URL, source type (article/thread/video/podcast/docs), and 1-line why-it-matters}

<!-- SERAPHIM:DISCOVERY_LINKS count="N" -->

<!-- SERAPHIM:PHASE_COMPLETE phase="discover" rounds="N" link_count="N" -->
```

**Step 6 — Update phase state.**
Write state via `writeState()` with phase="discover", status="complete".

**Key differences from old discover.md:**
- No parallel 4-track dispatch (solutions/anti-patterns/architecture/dependencies) — replaced by interactive rounds
- No `discovery/external.md` + `discovery/internal.md` — single `discovery.md`
- Human steers every round (not batch-and-wait)
- Links accumulate across rounds and get curated at the end

**Preserve from old discover.md:**

- Banner rendering call
- SERAPHIM marker wrapping (PHASE_START / PHASE_COMPLETE)

**New structure:**

**Step 1 — Parse arguments, read state, read discovery.md.**
Extract phase-id from $ARGUMENTS. Read `discovery.md` from `.seraphim/phases/{phaseId}/discovery.md`. If missing, abort with error: "Run /seraphim:discover first — Envision needs discovery material to converge."

**Step 2 — Render banner.**
Use `renderWingBanner('envision', phaseId)`.

**Step 3 — Generate discussion topics.**
AI analyzes discovery.md and generates 6-10 discussion topics (per D-10). Topics should cover:
- Core themes from the research
- Tensions or conflicts between findings
- Knowledge gaps that need resolution
- Scope and boundary questions
- Technical approach considerations

Present topics to human as a numbered list. Human can:
- Reorder topics (specify new order)
- Add new topics
- Remove topics
- Approve the list as-is

**Step 4 — Topic-by-topic discussion.**
For each topic in the approved order (per D-11):

a) AI presents the topic with relevant context from discovery.md
b) Conversational discussion with human
c) After each topic, AI evaluates clarity level internally
d) When clarity threshold is reached (enough topics discussed to write a coherent vision), AI offers: "I think we have enough clarity to draft the vision. Continue discussing remaining topics, or shall I draft?"
e) Human decides to continue or draft

**Step 5 — Gap research (if needed).**
Per D-09: If during convergence, knowledge gaps are discovered that need answers before the vision can solidify, Envision does targeted research using the `research-tracker.js` pattern. This is quick, focused research — not a full Discover round.

**Step 6 — Draft vision.md.**
Per D-07 and D-12: Write ONE unified vision (not alternatives). Output to `.seraphim/phases/{phaseId}/vision.md`:

```markdown
<!-- SERAPHIM:PHASE_START phase="envision" -->

# Vision: {project/feature name}

## Project Goals
{What this project aims to achieve}

## What It Does
{Functional description}

## How It Does It
{High-level technical approach}

## Constraints
{Budget, time, technical, compatibility constraints}

## Aspirations
{Stretch goals, quality bars, user experience ideals}

## Notes
{Open considerations, risks, assumptions}

## Outline Plan
{General phased approach — NOT detailed tasks, just logical phases}

<!-- SERAPHIM:PHASE_COMPLETE phase="envision" topics_discussed="N" -->
```

**Step 7 — Present draft to human for approval.**
Show the drafted vision. Human can request edits before finalizing. Once approved, write final vision.md.

**Key differences from old envision.md:**
- No APPROACH markers — ONE vision, not 3-5 alternatives (per D-07)
- No divergent brainstorming — convergent narrowing (per D-08)
- Discussion topics are AI-proposed, human-reordered (per D-10)
- Has its own mini-research capability for gap filling (per D-09)
- Scientific approach: categorize, theme, conflict-surface, resolve, distill (per D-08)

**Preserve from old envision.md:**
