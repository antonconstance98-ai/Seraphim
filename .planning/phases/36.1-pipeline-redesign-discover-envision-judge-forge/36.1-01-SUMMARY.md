# Phase 36.1 Plan 01: Rewrite Discover and Envision — Summary

**One-liner:** Interactive round-loop discovery with Perplexity+SearXNG and convergent single-vision Envision replacing divergent 3-5 alternatives.

## What Was Built

**Task 1 — discover.md rewrite**

The Discover command was completely rewritten from a batch parallel 4-track dispatcher to an
interactive human-steered research loop. Key changes:

- Replaced parallel 4-track dispatch (solutions / anti-patterns / architecture / dependencies) with
  a round-based loop where the human steers direction after each round
- Research uses Perplexity MCP (`mcp__perplexity__perplexity_search` / `mcp__perplexity__perplexity_research`)
  plus SearXNG at `localhost:8888` — both run each round
- Auto-retry on poor results: one automatic retry with refined query, then surfaces to human if
  still poor (D-05)
- After each round, presents findings and a 3-option steering prompt: go deeper / new direction /
  move to Envision (D-03)
- Links accumulate across all rounds; at the end, AI proposes 5-7 diverse curated links (articles,
  threads, videos, podcasts, docs) for human approval (D-04)
- Output: single `discovery.md` with `PHASE_COMPLETE phase="discover"` and `DISCOVERY_LINKS`
  markers — replaces the old `discovery/external.md` + `discovery/internal.md` split (D-06)

**Task 2 — envision.md rewrite**

The Envision command was completely rewritten from divergent brainstorming (3-5 alternatives) to
convergent vision building (one unified direction). Key changes:

- Reads `discovery.md` as prerequisite; aborts with clear error if missing
- AI analyzes discovery material and proposes 6-10 discussion topics; human reorders/adds/removes
  before discussion begins (D-10)
- Topic-by-topic conversational discussion — after each topic, AI checks whether clarity threshold
  is reached and offers to draft early (D-11)
- Gap research: if blocking knowledge gaps surface during discussion, uses `research-tracker.js`
  to do targeted lookups via Perplexity (D-09)
- Human reviews and approves draft vision before it is written to disk
- Output: `vision.md` with `PHASE_COMPLETE phase="envision"` marker, containing: Project Goals,
  What It Does, How It Does It, Constraints, Aspirations, Notes, Outline Plan (D-12)
- Zero `SERAPHIM:APPROACH` markers — convergent not divergent (D-07)
