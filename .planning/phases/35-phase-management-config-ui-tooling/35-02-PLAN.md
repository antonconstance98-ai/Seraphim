- `description: "Complete and archive the current milestone"`
- `argument-hint: "[milestone-version]"`
- `allowed-tools: ["Read", "Write", "Bash"]`

- `description: "Create a clean PR branch without .planning/ artifacts"`
- `argument-hint: "[branch-name]"`
- `allowed-tools: ["Read", "Bash"]`
- Step 1: Resolve project root
- Step 2: Detect base branch (`main` or `master`) via `git remote show origin | grep 'HEAD branch'`

- Step 5: Create branch `pr/{branch-name}` from base, cherry-pick non-planning-only commits in order.
- Step 6: Report: "Created branch pr/{name} with N commits (M planning-only commits excluded)"
