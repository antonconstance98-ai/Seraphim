**hook-signal.js** — Shared state temp file module (per D-02: shared state over advisory text parsing):

Create `~/.claude/hooks/hook-signal.js` exporting three functions:

1. `writeHookSignal(sessionId, toolName, key, value)` — Reads existing temp file at `/tmp/claude-hook-{sessionId}-{tsKey}-{toolName}.json` (where `tsKey = new Date().toISOString().slice(0,19)`), merges `{[key]: value}`, writes back with `fs.writeFileSync`. Uses `toolName` in key per Pitfall 2 (prevents cross-turn collision). If file doesn't exist, creates it. Silent catch on errors.

2. `readHookState(sessionId, toolName)` — Reads the temp file for the given session+tool combo, returns parsed JSON or `{}` on error.

3. `cleanupHookState(sessionId, toolName)` — Deletes the temp file. Called by decision-logger after reading.

The `tsKey` uses the CURRENT second (`new Date().toISOString().slice(0,19)`). All hooks in the same chain execute within the same second, so this provides a stable shared key.

**decision-logger.js** — PostToolUse + Stop decision capture hook:

Create `~/.claude/hooks/decision-logger.js` as a dual-event hook (handles both PostToolUse and Stop). Structure:

1. Stdin timeout guard: `setTimeout(() => process.exit(0), 5000)` (5s, lightweight hook)
2. Read stdin JSON, extract `session_id`, `cwd`, `tool_name`, and detect event type:
   - PostToolUse: `data.hook?.event === 'PostToolUse'` or `data.tool_name` is present
   - Stop: `data.hook?.event === 'Stop'` or `data.stop_hook_active !== undefined`
3. For PostToolUse events:
   - Read shared state via `readHookState(sessionId, toolName)` from hook-signal.js
   - Build decision-log.jsonl record with schema from research Pattern 3:
     ```
     { timestamp, session_id, project, cwd, event_type: "PostToolUse",
       tool_name, file_ext, diff_lines_changed,
       scan_triggered, scan_verdict, scan_issues_count, scan_model_latency_ms, scan_hook_latency_ms,
       review_verdict: null, review_block_category: null, review_model_latency_ms: null, review_hook_latency_ms: null,
       outcome: null, dismissed_at: null,
       task_type: classifyTaskType12(toolName, filePaths, diffStats, "PostToolUse"),
       config_snapshot: { routing_disabled, scan_skip_threshold, compress_tool_output_tokens, adaptive } }
     ```

   - Extract `file_ext` from `data.tool_input?.file_path` or first file in tool result
   - Extract `diff_lines_changed` from shared state (post-scan writes this) or null
   - Cleanup shared state file after reading
4. For Stop events:
   - Read shared state via `readHookState(sessionId, "Stop")`
   - If no shared state exists (review gate exited early), exit silently (per Pitfall 6 — no record for skipped reviews)
   - Build record with `event_type: "Stop"`, review_verdict, review_block_category, review latencies
   - task_type: `classifyTaskType12(null, null, null, "Stop")`
5. Append record to `{cwd}/.planning/decision-log.jsonl` using `fs.appendFileSync`
6. Output empty JSON (no advisory output — decision-logger is silent)

**classifyTaskType12** — exported function implementing 12-category taxonomy (per D-06):

Priority-ordered classification:
1. `security-scan` — file path contains auth/login/password/token/session/crypto/rbac/acl/.env/secret
2. `test-write` — ALL files match test patterns (`.test.`, `.spec.`, `__tests__/`, `tests/`)
3. `bulk-ops` — >10 files OR all files match style/data extensions (.css/.json/.yaml/.xml/.csv)
4. `hook-dev` — ANY file in `~/.claude/hooks/` OR path contains `hooks` + `.js` extension
5. `plan-review` — event_type is "Stop" or "SubagentStop"
6. `architecture` — file path contains design/architect/schema/interface + is .js/.ts
7. `refactor` — tool is Edit/MultiEdit on existing file with >50% lines changed
8. `doc-update` — ALL files are .md/.txt/.rst or in `/docs/`
9. `debug` — file path contains debug/fix/hotfix/patch
10. `explain` — no tool call (null toolName) or file is RESEARCH.md/CONTEXT.md
11. `implementation` — new .js/.ts/.py file (default for code files)
12. `review` — fallback default

Function signature: `classifyTaskType12(toolName, filePaths, diffStats, eventType)` where `filePaths` is array of strings, `diffStats` is `{ linesChanged, linesAdded, linesRemoved }` or null, `eventType` is "PostToolUse"/"Stop"/"SubagentStop".
