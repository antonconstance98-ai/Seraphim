**parseForgeActions(output):**
```javascript
function parseForgeActions(output) {
  return output.split('\n')
    .filter(l => l.trim().startsWith('{'))
    .map(l => { try { return JSON.parse(l); } catch { return null; } })
    .filter(Boolean);
}
```

**available() — CRITICAL: must use inference probe, NOT /api/tags (EXEC-07):**
```javascript
async function available() {
  try {
    const client = getClient(PROBE_TIMEOUT_MS);
    const controller = new AbortController();
    const timer = setTimeout(() => controller.abort(), PROBE_TIMEOUT_MS);
    timer.unref();
    await client.chat.completions.create({
      model: MODEL_TAG,
      messages: [{ role: 'user', content: 'ping' }],
      max_tokens: 1
    }, { signal: controller.signal });
    clearTimeout(timer);
    return true;
  } catch {
    return false;
  }
}
```
This probe forces ollama to actually load the model into VRAM, catching cold-start failures that /api/tags would miss.

**Key design insight (from research Pitfall 7):** MCP tools are only accessible within a Claude Code session, NOT from standalone Node.js. The "MCP first" path per D-01 means: when the executor is called from a Claude command that has MCP access, the caller passes `opts.mcpAvailable: true` and the executor returns a structured MCP invocation request instead of making the call itself. When `opts.mcpAvailable` is false or absent, the executor uses the direct API path.

**Constants:**
- `PERPLEXITY_BASE_URL = 'https://api.perplexity.ai'` (NO /v1 suffix — adding /v1 causes 404)
- `DEFAULT_MODEL = 'sonar-pro'`
- `TIMEOUT_MS = 60000` (60s)

**OpenAI client setup (same pattern as MiniMax):**
```javascript
let OpenAI;
try { OpenAI = require('openai').OpenAI; }
catch (e) { OpenAI = require('/home/alucard/.npm-global/lib/node_modules/openai').OpenAI; }
```

**execute(prompt, opts):**
1. **MCP path** (per D-01, D-02): If `opts.mcpAvailable === true`, return a structured request object that the Claude command caller can use to invoke MCP:
   ```javascript
   return {
     success: true,
     output: null,
     tokens: null,
     cost: 0,
     raw_usage: null,
     error: null,
     mcpRequest: {
       tool: 'mcp__perplexity__perplexity_search',
       args: { query: prompt }
     }
   };
   ```
   The caller (Claude command) is responsible for invoking this MCP tool and processing the result.

2. **Direct API path** (fallback when MCP unavailable):
   - Check `process.env.PERPLEXITY_API_KEY` — if missing, return `{success: false, error: {error_type: 'auth', message: 'PERPLEXITY_API_KEY not set and MCP unavailable', retriable: false}}`
   - Create OpenAI client with `baseURL: PERPLEXITY_BASE_URL`, `apiKey: process.env.PERPLEXITY_API_KEY`, `timeout: TIMEOUT_MS`
   - Call `client.chat.completions.create({ model: opts.model || DEFAULT_MODEL, messages: [{role: 'system', content: 'Be precise and cite sources.'}, {role: 'user', content: prompt}] })`
   - Extract text: `response.choices[0].message.content`
   - Extract citations: `response.citations || []` (Perplexity extension field)
   - Append citations to output: `\n\n## Sources\n${citations.map((c, i) => '[' + (i+1) + '] ' + c).join('\n')}`
   - Extract usage: `response.usage || {}`
   - Compute tokens: `normalizeUsage(usage, 'openai')`
   - Compute cost: `computeOpenAICost(usage.prompt_tokens || 0, usage.completion_tokens || 0, 'perplexity-sonar')`
   - Return `{ success: true, output, tokens, cost, raw_usage: usage, error: null, citations }`

- On failure per D-04/D-05:
  - 429 -> `error_type: 'rate_limit', retriable: true`
  - 401/403 -> `error_type: 'auth', retriable: false`
  - timeout -> `error_type: 'timeout', retriable: true`
  - other -> `error_type: 'unknown', retriable: false`

**available():**
- Return `true` if EITHER condition is met:
  - `process.env.PERPLEXITY_API_KEY` is set (direct API available)
  - The function is being called in a context where MCP might be available (always return true as a hint — the actual MCP check happens at call time via opts.mcpAvailable)
- Simplified: `return !!process.env.PERPLEXITY_API_KEY` — MCP availability is opaque at this level. If the key is missing, dispatch will check if the calling context has MCP access.
- NEVER throw

**stream(prompt, opts):** Delegate to execute().
