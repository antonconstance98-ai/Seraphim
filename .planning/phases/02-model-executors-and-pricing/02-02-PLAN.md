<!-- Unified executor contract from 02-RESEARCH.md Pattern 1 -->

Every executor exports exactly three functions:
```javascript
module.exports = {
  async execute(prompt, opts) {},  // -> {success, output, tokens, cost, error, raw_usage}
  async stream(prompt, opts) {},   // -> same shape (falls back to execute for non-streaming)
  async available() {}             // -> boolean, NEVER throws
};
```

Result shape:
```javascript
{
  success: boolean,
  output: string,
  tokens: { input_tokens: N, output_tokens: N, ... },
  cost: number,        // USD float, 0 for free models
  raw_usage: object,   // original provider response usage object
  error: null | { error_type: string, message: string, retriable: boolean }
}
```

Error types (per D-05): 'unavailable', 'timeout', 'rate_limit', 'auth', 'parse', 'unknown'

From lib/pricing.js (created in Plan 01):
```javascript
exports: { PRICING, computeAnthropicCost, computeGeminiCost, computeOpenAICost, computeFreeCost, computeCostForModel, normalizeUsage }
```
