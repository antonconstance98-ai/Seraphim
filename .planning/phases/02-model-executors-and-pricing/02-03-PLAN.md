const MODEL_MAP = {

**execute(prompt, opts):**
- Check `process.env.GEMINI_API_KEY` — if missing, return `{success: false, error: {error_type: 'auth', message: 'GEMINI_API_KEY not set', retriable: false}}`
- Create `new GoogleGenAI({ apiKey })` per call (stateless, no shared client)
- Resolve model: `MODEL_MAP[opts.model] || opts.model || DEFAULT_MODEL`
- Build config object:
  - If `opts.searchGrounding === true`: add `tools: [{ googleSearch: {} }]` (NOT `google_search_retrieval`)
  - If `opts.thinkingMode === true`: add `thinkingConfig: { thinkingBudget: -1, thinkingLevel: ThinkingLevel.HIGH }`
  - Both can be active simultaneously
- Call `ai.models.generateContent({ model, contents: prompt, config })` inside retry loop
- Extract text: `response.text`
- Extract usage: `response.usageMetadata || {}`
- Extract grounding metadata if present: `response.candidates?.[0]?.groundingMetadata` — append to output as `\n\n<!-- GROUNDING_METADATA: ${JSON.stringify(metadata)} -->` if exists
- Compute tokens via `normalizeUsage(usage, 'gemini')`
- Compute cost via `computeGeminiCost(usage.promptTokenCount || 0, usage.candidatesTokenCount || 0, pricingKey)`
- Return `{ success: true, output, tokens, cost, raw_usage: usage, error: null }`

**429 retry loop (Pitfall 3 from research):**
- Backoff delays: `Math.min(5000 * Math.pow(2, attempt), 60000) + Math.random() * 1000`
- On 429: retry up to MAX_RETRIES times with backoff
- On 401: return immediately with `error_type: 'auth', retriable: false`
- On 400: return immediately with `error_type: 'parse', retriable: false` (client error)
- On other errors: return `error_type: 'unknown', retriable: false`
- Error status detection: check `err.status || err.code || err.httpCode`

**available():**
- Return `!!process.env.GEMINI_API_KEY` — API key presence is sufficient; don't burn quota on probe
- NEVER throw

**stream(prompt, opts):**
- Delegate to `execute(prompt, opts)` for now (streaming deferred per FUTR-04)

**Per D-04:** Executor NEVER throws — all paths return the result object.

Export: `module.exports = { execute, stream, available }`
