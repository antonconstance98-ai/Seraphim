**Per-provider cost functions** (per D-04, COST-01 — never a shared formula):
- `computeAnthropicCost(inputTokens, cacheReadTokens, cacheWriteTokens, outputTokens, modelKey)` — cache_read is a POSITIVE charge at reduced rate, NOT a credit
- `computeGeminiCost(promptTokenCount, candidatesTokenCount, modelKey)` — simple input+output
- `computeOpenAICost(promptTokens, completionTokens, modelKey)` — for MiniMax, Perplexity, Codex API mode
- `computeFreeCost()` — returns 0 for Codex (Plus sub) and Qwen (local)
- `computeCostForModel(modelKey, rawUsage)` — dispatcher that picks the right function based on modelKey, uses `normalizeUsage` internally

**normalizeUsage(rawUsage, provider)** — maps four incompatible token schemas to canonical `{input_tokens, output_tokens, cache_read_input_tokens?, cache_creation_input_tokens?, thoughts_tokens?}`:
- provider 'anthropic': maps input_tokens, output_tokens, cache_read_input_tokens, cache_creation_input_tokens
- provider 'gemini': maps promptTokenCount -> input_tokens, candidatesTokenCount -> output_tokens, thoughtsTokenCount -> thoughts_tokens
- provider 'openai': maps prompt_tokens -> input_tokens, completion_tokens -> output_tokens
- provider 'ollama': maps prompt_eval_count (fallback prompt_tokens) -> input_tokens, eval_count (fallback completion_tokens) -> output_tokens

All cost functions return `parseFloat(cost.toFixed(6))` for 6 decimal precision.

Export: `{ PRICING, computeAnthropicCost, computeGeminiCost, computeOpenAICost, computeFreeCost, computeCostForModel, normalizeUsage }`

Create `~/.claude/plugins/seraphim/hooks/token-logger.js` — a PostToolUse hook that logs token usage for all nine models.

**Preserve from fork source:**
- 10s stdin timeout guard with `setTimeout(() => process.exit(0), 10000)` and `.unref()` on the timer
- stdin JSON parsing pattern (read all stdin, parse on 'end')
- Silent exit on any error (hooks must never block)

**Change from fork source:**
- Instead of looking for `[CODEX_RESULT]` marker, look for `[SERAPHIM_RESULT]` marker in tool_result
- Import `normalizeUsage` and `computeCostForModel` from `path.join(__dirname, '../lib/pricing')`
- After marker extraction, parse JSON payload expecting: `{model, provider, phase, raw_usage}`
- Call `normalizeUsage(raw_usage, provider)` to get canonical token fields
- Call `computeCostForModel(model, raw_usage)` to get cost_usd
- Build record: `{timestamp, phase, model, provider, tokens: normalizedTokens, raw_usage, cost_usd}`
- Append JSONL to `path.join(cwd, '.seraphim', 'token-log.jsonl')` (NOT .planning/ — Seraphim uses .seraphim/)
- Output advisory JSON to stdout: `{"result": "Token usage logged: {input_tokens}in/{output_tokens}out, cost: ${cost_usd}"}`

**COST-06 compliance:** The `raw_usage` field from the input payload is stored verbatim in the JSONL record — no transformation, no field filtering. This preserves the original provider-specific fields for debugging.

**Token logger record schema:**
```json
{
  "timestamp": "ISO8601",
  "phase": "string",
  "model": "string (pricingKey)",
  "provider": "anthropic|gemini|openai|ollama",
  "tokens": {"input_tokens": N, "output_tokens": N, ...},
  "raw_usage": {/* original provider object verbatim */},
  "cost_usd": 0.001234
}
```
