**Library mode (exported function):**

`async function compress(text, opts)` per D-02:
- `opts.maxOutputTokens` — default 1500 (keeps output under 6K chars, well within 10K additionalContext limit)
- `opts.purpose` — string guiding compression behavior (per D-07). Supported purposes: 'summarize code diff', 'condense tool output', 'compress conversation', 'condense file content'. Falls back to generic preservation rules for unknown purposes.
- Estimate input tokens: `Math.round(text.length / 4)` (4 chars per token heuristic)
- Lazy-require `runMinimax` from `/home/alucard/.claude/hooks/minimax-exec` (same lazy pattern as Phase 11)
- Build purpose-aware compression prompt via `buildCompressionPrompt(text, purpose)` per D-07:
  - 'summarize code diff': preserve file names, function signatures, nature of changes, error handling
  - 'condense tool output': preserve error messages (verbatim), key data values, actionable warnings, success/failure
  - 'compress conversation': preserve decisions, blockers, action items, file paths
  - 'condense file content': preserve function/class signatures, public API, constants, critical logic
  - System prompt: 'You are a technical summarizer. Preserve all actionable information.'
- Call `runMinimax(prompt, { maxTokens, timeoutMs: 60000, systemPrompt })` — 60s timeout accounts for MiniMax pre-answer latency
- On failure: return `{ success: false, text: '', error: result.error }`
- On success: strip think tags via `result.text.replace(/<think>[\s\S]*?<\/think>\s*/g, '').trim()`, prepend header `[Compressed from ~{N}K tokens]` per D-08
- Truncate final output to 9500 chars max (leave 500-char buffer for additionalContext 10K limit)
- Return: `{ success: true, text: headerPlusCompressed, tokens: result.tokens, cost: result.cost, originalChars: text.length, compressedChars: output.length }`

**Hook mode (PostToolUse):**

Guarded by `if (require.main === module) { runAsHook(); }`. Inside `runAsHook()`:
- Read stdin with 10s timeout guard (same as minimax-post-scan.js)
- Parse JSON, extract `data.tool_result`, `data.session_id`, `data.cwd`
- Guard: `const toolResult = typeof data.tool_result === 'string' ? data.tool_result : '';` (pitfall 2 from research)
- Double-compression guard per research pitfall 4: if `toolResult.startsWith('[Compressed from ~')`, exit(0) silently
- Read project settings: `path.join(cwd, '.claude', 'settings.json')` to get minimax config
- If `minimaxConfig.enabled === false`, exit(0)
- Compute threshold: `(minimaxConfig.compress_tool_output_tokens || 10000) * 4` chars (D-03, D-04)
- If `toolResult.length <= threshold`, exit(0) silently (most common path)
- Call `compress(toolResult, { purpose: 'condense tool output', maxOutputTokens: 1500 })`
- If compression succeeds: write `{ hookSpecificOutput: { hookEventName: 'PostToolUse', additionalContext: result.text } }` to stdout
- Token logging: lazy-require `computeCodexCostStrict` from `/home/alucard/.claude/hooks/codex-pricing`, log to `.planning/token-log.jsonl` in `cwd` with `task_type: 'context-compress'`, `model: 'minimax-m2.7'`, `source: 'api'`. Match exact schema from minimax-post-scan.js lines 311-329.
- All errors: exit(0) silently (D-08 equivalent fail-silent behavior)

**Module exports:** `module.exports = { compress };`

Important: Do NOT use `execSync` or `execFileSync` in this module. Compression is pure API call, no subprocess needed.
