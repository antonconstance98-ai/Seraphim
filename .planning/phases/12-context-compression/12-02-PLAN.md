Modify `~/.claude/hooks/gsd-context-monitor.js` to inject a self-summarization directive when context usage exceeds the `compress_context_pct` threshold (D-05).

**Design rationale:** The monitor reads usage metrics from `/tmp/claude-ctx-{session_id}.json` but has NO access to the actual conversation text. It cannot literally compress conversation content. Instead, when the threshold is hit, we append a directive telling the agent to mentally self-compress. This is zero-cost (no MiniMax API call), zero-latency (string concatenation only), and immediately effective because the agent receives it via additionalContext.

**Change 1 — Make the on('end') callback async:**

Find: `process.stdin.on('end', () => {`
Replace: `process.stdin.on('end', async () => {`

This is safe — Node.js EventEmitter accepts async functions as listeners. The existing outer try/catch still catches synchronous throws. For async rejections, Node.js v22 treats unhandled rejections as warnings by default (does not crash the process), and the monitor already exits(0) in all code paths.

**Change 2 — Read minimax config for compression threshold:**
