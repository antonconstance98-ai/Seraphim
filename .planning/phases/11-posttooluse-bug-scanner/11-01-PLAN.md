  <action>
Create `~/.claude/hooks/minimax-post-scan.js` implementing a PostToolUse hook that scans code diffs with MiniMax.

**Structure (follow codex-token-logger.js stdin-reading pattern):**

1. **Stdin reading** -- 10s stdinTimeout, JSON.parse input, wrap everything in try/catch that exits 0 on any error (per D-08).

2. **Tool filter** -- Only process Write, Edit, MultiEdit tool_name values (per D-01). Exit 0 for all others (Bash, Agent, Task).

3. **File path extraction** -- Read `data.tool_input.file_path`. If missing, exit 0.

4. **Code file filter (per D-01)** -- `isCodeFile(filePath)` function using a Set of code extensions:
   `.js`, `.ts`, `.jsx`, `.tsx`, `.mjs`, `.cjs`, `.py`, `.rb`, `.go`, `.rs`, `.java`, `.c`, `.cpp`, `.sh`, `.bash`, `.zsh`, `.html`, `.css`, `.scss`, `.sql`
   Also exclude paths containing `.planning/`, `settings.json`, or ending in `.md`.

5. **Config read** -- Read `.claude/settings.json` from `data.cwd` to get `minimax.scan_skip_threshold` (default: 5 per D-04). Also check `minimax.enabled === false` to bail early.

6. **Git diff extraction (per D-02)** -- `getFileDiff(filePath, cwd)` function:
   - First try: `execSync('git diff HEAD -U5 -- "${filePath}"', { cwd, timeout: 5000, maxBuffer: 256*1024 })` for tracked files.
   - Second try (untracked): `execSync('git diff --no-index /dev/null "${filePath}"', ...)` -- note this exits non-zero when files differ; read from `e.stdout`.
   - Return empty string on any error. Check for `Binary files` marker and return empty if found.

7. **Trivial edit detection (per D-03, D-04)** -- `isTrivialEdit(diff, threshold)` function:
   - Count changed lines (starting with `+` or `-`, excluding `+++`/`---` headers).
   - If count >= threshold, NOT trivial (return false).
   - If count < threshold, check if all changed lines are comments (`//`, `#`, `/*`, `*`, `-- `), blank, or string-literal-only (`/^['"\x60].*['"\x60][,;]?$/`). If all non-meaningful, return true (skip scan).

8. **Scan prompt (per D-06, Claude's discretion)** -- `buildScanPrompt(diff, filePath)` function:
   - Include file basename and the full file path for context.
   - Two-pronged: "Analyze for bugs AND security vulnerabilities" (per CONTEXT.md specifics).
   - Output format: `[BUG] filename:linenum -- description` or `[SECURITY] filename:linenum -- description`.
   - "If nothing found, output exactly: CLEAN"
   - "Be concise -- one line per finding, no explanations"
   - Truncate diff to 3000 chars max before sending (append "... (truncated)" if clipped).

9. **MiniMax call** -- `const { runMinimax } = require('/home/alucard/.claude/hooks/minimax-exec')` (use absolute path). Call with `{ maxTokens: 1000, timeoutMs: 25000 }` (per D-06, max_tokens 1000; 25s timeout fits within 30s hook timeout with margin). Do NOT use `runWithFallback` -- use `runMinimax` directly (per research anti-patterns).

10. **Failure handling (per D-08)** -- If `result.success === false`, write error to stderr and exit 0. Never throw, never block.

11. **Token logging (per D-07)** -- Only if `result.success && result.tokens`:
    ```javascript
    const record = {
      timestamp: new Date().toISOString(),
      session_id: data.session_id || null,
      model: 'minimax-m2.7',
      source: 'api',
      task_type: 'post-scan',
      tokens: {
        input: result.tokens.input_tokens || 0,
        cached_input: result.tokens.cached_input_tokens || 0,
        output: result.tokens.output_tokens || 0
      },
      cost_usd: computeCodexCostStrict(result.tokens, 'minimax-m2.7') || 0
    };
    ```
    Append to `path.join(cwd, '.planning', 'token-log.jsonl')` via `fs.appendFileSync`. Create `.planning/` dir with `fs.mkdirSync({ recursive: true })` first.

12. **Advisory output (per D-05)** -- Only if findings exist and text !== 'CLEAN':
    ```javascript
    process.stdout.write(JSON.stringify({
      hookSpecificOutput: {
        hookEventName: 'PostToolUse',
        additionalContext: '[BUG SCAN] ' + path.basename(filePath) + ':\n' + findings
      }
    }));
    ```
    If CLEAN: exit 0 silently (do not pollute Claude's context on every file write).

13. **Final exit** -- Always `process.exit(0)` at the end of the main try/catch (per D-08).

**Important implementation notes:**
- Use `'use strict';` at top.
- Require `fs`, `path`, `child_process.execSync` at top.
- Lazy-require `minimax-exec` and `codex-pricing` only after confirming scan will proceed (steps 9-11) to avoid unnecessary SDK load on skipped scans.
- All require paths are absolute: `/home/alucard/.claude/hooks/minimax-exec` and `/home/alucard/.claude/hooks/codex-pricing`.
- No debounce logic (per research recommendation -- each write triggers its own scan; cost is $0.01-0.03).
