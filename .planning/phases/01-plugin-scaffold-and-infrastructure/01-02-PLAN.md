Create `~/.claude/plugins/seraphim/lib/config.js` implementing per-project config management for `.seraphim/config.json`.

Module exports: `read(projectRoot)`, `write(projectRoot, config)`, `validate(config)`, `CONFIG_DEFAULTS`.

CONFIG_DEFAULTS object:
```javascript
const CONFIG_DEFAULTS = {
  profile: 'moderate',
  opus_enabled: true,
  overrides: {},
  max_loops: 2,
  project_type: 'code'
};
```

`read(projectRoot)` function:
1. Build path: `path.join(projectRoot, '.seraphim', 'config.json')`
2. If file does not exist, return `{ ...CONFIG_DEFAULTS, _projectRoot: projectRoot }`
3. If file exists, read with `fs.readFileSync(configPath, 'utf8')`, parse JSON
4. Merge: `{ ...CONFIG_DEFAULTS, ...parsed, _projectRoot: projectRoot }`
5. Wrap in try/catch — on parse error, log warning to stderr and return defaults

`write(projectRoot, config)` function:
1. Build path: `path.join(projectRoot, '.seraphim', 'config.json')`
2. Clone config, delete `_projectRoot` from the clone (internal field, never persisted — Pitfall from research)
3. `fs.mkdirSync(path.dirname(configPath), { recursive: true })`
4. `fs.writeFileSync(configPath, JSON.stringify(toWrite, null, 2))`

`validate(config)` function:
1. Check `config.profile` is a string
2. Check `config.opus_enabled` is boolean
3. Check `config.overrides` is an object (not null, not array)
4. Check `config.max_loops` is a number between 1 and 3 (loop cap above 3 is out of scope per REQUIREMENTS.md)
5. Check `config.project_type` is one of: 'code', 'research', 'writing', 'science', 'mixed'
6. Return `{ valid: boolean, errors: string[] }`

Use `'use strict'` at top. Use `const fs = require('fs')` and `const path = require('path')`. No external dependencies.

Create `~/.claude/plugins/seraphim/lib/phase-state.js` implementing phase state tracking with per-increment disk writes.

Module exports: `readState(projectRoot, phaseId)`, `writeState(projectRoot, phaseId, state)`, `incrementLoop(projectRoot, phaseId, loopType)`, `incrementRetry(projectRoot, phaseId, taskId)`, `markComplete(projectRoot, phaseId)`, `reset(projectRoot, phaseId)`.

State file path: `path.join(projectRoot, '.seraphim', 'phases', phaseId, 'state.json')`

State file schema (the default when creating fresh):
```json
{
  "phase_id": "{phaseId}",
  "created_at": "ISO timestamp",
  "last_updated": "ISO timestamp",
  "completed": false,
  "loops": {
    "judge_envision": 0,
    "crucible_forge": 0
  },
  "retries": {},
  "reset_at": "ISO timestamp"
}
```

`readState(projectRoot, phaseId)`:
1. Build statePath
2. If file does not exist, return fresh default state with current timestamps
3. If file exists, read and parse JSON
4. Wrap in try/catch — on parse error, return fresh default state

`writeState(projectRoot, phaseId, state)`:
1. Build statePath
2. `fs.mkdirSync(path.dirname(statePath), { recursive: true })`
3. Update `state.last_updated` to current ISO timestamp
4. `fs.writeFileSync(statePath, JSON.stringify(state, null, 2))`

`incrementLoop(projectRoot, phaseId, loopType)`:
1. Read current state via readState
2. Initialize `state.loops[loopType]` to 0 if missing
3. Increment: `state.loops[loopType] += 1`
4. Write to disk immediately via writeState (CRITICAL — Pitfall 6: in-memory only counters lost on crash)
5. Return the new count

`incrementRetry(projectRoot, phaseId, taskId)`:
1. Read current state
2. Initialize `state.retries[taskId]` to 0 if missing
3. Increment: `state.retries[taskId] += 1`
4. Write to disk immediately
5. Return the new count

`markComplete(projectRoot, phaseId)`:
1. Read current state
2. Set `state.completed = true`
3. Write to disk immediately

`reset(projectRoot, phaseId)`:
1. Create fresh default state with `reset_at` set to current ISO timestamp
2. Write to disk (this clears loop counters from prior runs — Pitfall 4 from research)

Use `'use strict'`. Node.js built-ins only (fs, path). Every mutation writes to disk before returning.

Module exports: `resolveExecutorId(phase, config)`, `resolveProfile(profileName, projectRoot)`.

Resolution order is LOCKED (from roadmap decision): override > opus_enabled flag > profile preset.

`resolveExecutorId(phase, config)` function:
```
1. Level 1 — Per-phase override:
   if (config.overrides && config.overrides[phase]) return config.overrides[phase]

2. Level 2 — Load profile definition:
   const builtinProfiles = require('../config/profiles.json')
   const models = require('../config/models.json')
   let profileDef

   if (builtinProfiles[config.profile]) {
     profileDef = builtinProfiles[config.profile]
   } else {
     // Custom profile: load from .seraphim/profiles/{name}.json (per D-04)
     const customPath = path.join(config._projectRoot, '.seraphim', 'profiles', config.profile + '.json')
     if (!fs.existsSync(customPath)) {
       return { error: "Profile '" + config.profile + "' not found in built-in profiles or .seraphim/profiles/" }
     }
     profileDef = JSON.parse(fs.readFileSync(customPath, 'utf8'))
   }

   let modelId = profileDef.phases[phase]

   // Check for unassigned slot (naked profile or incomplete custom profile)
   if (modelId === null || modelId === undefined) {
     return { error: "Phase '" + phase + "' has no model assigned in profile '" + config.profile + "'. Use /seraphim:override to assign a model." }
   }

3. Level 3 — opus_enabled check:
   if (config.opus_enabled === false && models[modelId] && models[modelId].isOpus) {
     if (profileDef.opusFallback) {
       modelId = profileDef.opusFallback
     } else {
       return { error: "opus_enabled is false but profile '" + config.profile + "' has no opusFallback defined" }
     }
   }

4. Return modelId (string) on success, or { error: string } on failure
```

`resolveProfile(profileName, projectRoot)` function:
1. Check built-in profiles first: `require('../config/profiles.json')`
2. If found, return the profile definition object
3. If not found, check `.seraphim/profiles/{profileName}.json` in projectRoot
4. If found, read and parse. Validate it has `phases` object with 10 slots and `opusFallback` field. Return the profile definition.
5. If neither found, return `{ error: "Profile not found" }`

This handles Pitfall 3 from research: dispatch must check both built-in and custom profile locations. Pitfall 5: custom profiles missing opusFallback are caught at Level 3.

Use `'use strict'`. Node.js built-ins only (fs, path).
