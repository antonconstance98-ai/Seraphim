  <action>
    **Create `~/.claude/plugins/seraphim/commands/inbox.md`** that aggregates pending human tasks.

    Frontmatter:
    ```yaml
    ---
    description: "Show all pending human tasks across active features"
    argument-hint: ""
    allowed-tools: ["Read", "Bash"]
    ---
    ```

    **Step 1 — Resolve project root** (walk-up pattern).

    **Step 2 — Scan for tasks**

    Run a `node -e` script that:
    1. Requires `roadmap.js` and `markers.js`
    2. Reads roadmap — get all features with status `in-progress`
    3. For each in-progress feature, scans `.seraphim/phases/*/forge-log.md` files (using `fs.readdirSync` on `.seraphim/phases/` then reading each `forge-log.md`)
    4. Parses each forge-log.md with `parseMarkers()` to extract TASK markers
    5. Filters for tasks with `assignee: 'human'` and `status: 'pending'`
    6. Reads `.seraphim/task-completions.jsonl` (if exists) — parse each line as JSON, collect completed task IDs into a Set
    7. Filters out tasks whose ID is in the completions Set
    8. Groups remaining tasks by project name (from config.json `project_name` or directory name), then by task type (per D-05)

    **Step 3 — Render output** matching the RESEARCH.md inbox pattern:

    ```
    ═══════════════════════════════════════════════════
     SERAPHIM  Inbox
    ═══════════════════════════════════════════════════
     {project-name}  [{N} tasks]
       decisions  ({count})
         [ ] T-001  Choose primary color scheme for dashboard
       research   ({count})
         [ ] T-002  Evaluate Drizzle ORM vs raw pg
       review     ({count})
         [ ] T-003  Review feat-001 Crucible output

    Run /seraphim:done {task-id} to mark a task complete.
    ```

    Valid task types per TASK-02: `decision`, `research`, `review`, `validation`, `skills`. Only show type groups that have tasks. If no tasks found, print: "Inbox empty. No pending human tasks."

    Per D-08: If roadmap.json missing or no phases directory, show empty inbox — never error.
  </action>

    ```yaml
    ---
    description: "Mark a human task complete without re-running the pipeline"
    argument-hint: "<task-id>"
    allowed-tools: ["Read", "Bash"]
    ---
    ```

    **Step 1 — Parse arguments**: Extract task-id (first positional arg, e.g., `T-001`). If missing, abort with usage.

    **Step 2 — Resolve project root** (walk-up pattern).

    **Step 3 — Verify task exists**

    Run a `node -e` script that:
    1. Scans `.seraphim/phases/*/forge-log.md` files with `parseMarkers()` to find a TASK marker matching the given task-id
    2. If not found, print "Task {task-id} not found in any forge-log." and exit
    3. Checks `.seraphim/task-completions.jsonl` — if task-id already completed, print "Task {task-id} is already complete." and exit

    **Step 4 — Mark complete**

    Append a JSON line to `.seraphim/task-completions.jsonl`:
    ```json
    {"task_id":"T-001","completed_at":"2026-04-09T12:00:00Z"}
    ```

    Use `fs.appendFileSync`. Create the file if it doesn't exist. Create `.seraphim/` dir if missing.

    **Step 5 — Confirm**

    Print:
    ```
    Task complete.
      ID:   T-001
      Type: decision
      Desc: Choose primary color scheme for dashboard

    Remaining tasks: /seraphim:inbox
    ```
