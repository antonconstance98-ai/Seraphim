   - Props: `{ milestones: MilestoneSnapshot[] }`
   - Import MilestoneSnapshot from `@/lib/types`
   - Find the active milestone: first with status 'in-progress', else first with status 'planned', else last one
   - If no milestones, return null (render nothing)
   - Render inside existing card flow:
     ```
     <div className="mt-3 mb-1">
       <div className="flex justify-between text-xs text-gray-500 mb-1">
         <span className="truncate max-w-[60%]">{milestone.name}</span>
         <span>{milestone.complete_count}/{milestone.feature_count} features</span>
       </div>
       <div className="w-full bg-white/10 rounded-full h-1.5">
         <div className="bg-indigo-500 h-1.5 rounded-full transition-all"
              style={{ width: `${percent}%` }}
              role="progressbar" aria-valuenow={percent} aria-valuemin={0} aria-valuemax={100} />
       </div>
     </div>
     ```
   - percent = `Math.round((milestone.complete_count / Math.max(milestone.feature_count, 1)) * 100)`

2. **NeedsAttentionBadge.tsx** -- Server Component per D-04.
   - Props: `{ tasks: HumanTaskSnapshot[]; milestones: MilestoneSnapshot[] }`
   - Import types from `@/lib/types`
   - Determine needsAttention: any task with urgency === 'high' and status !== 'done', OR any milestone with status === 'blocked'
   - If not needsAttention, return null
   - Render: `<span className="text-xs bg-red-500/15 text-red-400 border border-red-500/30 px-2 py-0.5 rounded-full" aria-label="This project needs attention">Needs attention</span>`

3. **CostSparkline.tsx** -- Client Component per research pattern. Chart.js mini line chart.
   - `'use client'` directive at top
   - Props: `{ data: { date: string; cost_usd: number }[] }`
   - Import `useEffect`, `useRef` from `react`
   - Use `useRef<HTMLCanvasElement>(null)` for canvas
   - Use `useRef<any>(null)` for chart instance (chartRef)
   - In useEffect (dependency: [data]):
     - If no data or data.length < 2, return early
     - `import('chart.js/auto').then(({ default: Chart }) => { ... })`
     - Destroy previous chart: `chartRef.current?.destroy()`
     - Create new Chart on canvasRef.current with type: 'line', data labels from data.map(d => d.date), dataset values from data.map(d => d.cost_usd)
     - Dataset config: `borderColor: 'rgb(99, 102, 241)'` (indigo-500), `borderWidth: 1.5`, `pointRadius: 0`, `tension: 0.4`, `fill: false`
     - Options: `responsive: false`, `plugins: { legend: { display: false } }`, `scales: { x: { display: false }, y: { display: false } }`
     - Store instance: `chartRef.current = chart`
   - Cleanup in useEffect return: `chartRef.current?.destroy()`
   - Render: `<canvas ref={canvasRef} width={96} height={48} aria-hidden="true" />`
   - If data.length < 2, render nothing (return null)
