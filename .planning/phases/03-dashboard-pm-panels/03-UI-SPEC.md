## Spacing Scale

Declared values (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge inner padding (`px-1`, `py-0.5`) |
| sm | 8px | Stacked list item gaps (`space-y-2`), inline label margins |
| md | 16px | Default element padding (`p-4`), tab content inner padding |
| lg | 24px | Card padding (`p-6`), section header bottom margin (`mb-6`) |
| xl | 32px | Between major sections (`mb-8`) |
| 2xl | 40px | Between tab-content sections (`mb-10`) — existing pattern from project detail page |
| 3xl | 48px | Page padding (`p-8`) — existing pattern from all pages |

Exceptions:
- Progress bar height: 6px (`h-1.5`) — sub-4px exception inherited from v3.0 ProjectCard; retain for visual consistency
- Tab indicator underline: 2px — fine-grain UI affordance, not a spacing token

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#111111` (page background `min-h-screen`) | Page canvas, outer background |
| Secondary (30%) | `#1a1a1a` (card/panel background) | All cards, section panels, table containers; `border border-white/10` always paired |
| Tertiary surface | `#242424` | List item rows inside cards (e.g. human task items in TaskList) |
| Accent (10%) | `indigo-500` (`#6366f1`) | Tab active indicator, progress bar fill, current-phase label, "Back" link, phase pills on run history |
| Attention semantic | `amber-400` / `amber-500` | Human tasks only: task card border, status badge, section heading, count badge, "needs attention" marker |
| Success semantic | `green-400` / `green-500` | Feature status: complete |
| Blocked semantic | `red-400` / `red-500` | Feature status: blocked |
| Planned semantic | `gray-400` / `gray-500` | Feature status: planned (default/neutral) |
| In-progress semantic | `blue-400` / `blue-500` | Feature status: in-progress |
| Destructive | not applicable | No destructive actions in this phase |

Accent reserved for: active tab indicator underline, milestone/feature progress bar fill, URL-linkable back navigation, phase run history pills. NOT used for generic text, borders, or backgrounds.

Attention (amber) reserved for: human task list items, human task count badges, "needs attention" project card badge, Tasks tab heading.

Color pairing rule (inherited from v3.0): every colored element uses `bg-{color}/15 text-{color} border border-{color}/30` pattern for badge/pill — never solid fills.

## Layout Contracts

### Tab Bar (Project Detail Page)

- URL-based routing: `?tab=metrics` (default) | `?tab=plan` | `?tab=tasks`
- Tab bar sits below page h1, above tab content
- Tab labels: `Metrics` | `Plan` | `Tasks` — sentence case, not uppercase
- Active tab: `text-white border-b-2 border-indigo-500 pb-2`
- Inactive tab: `text-gray-400 hover:text-gray-300 pb-2`
- Tab bar container: `flex gap-6 border-b border-white/10 mb-8`
- Tab content: full width, no horizontal scroll on desktop

### Plan Tab — Milestone-Feature Tree

- Container: `bg-[#1a1a1a] border border-white/10 rounded-xl p-6`
- Milestone row: `flex items-center gap-3 py-3 border-b border-white/5`
  - Status dot (8px, status color per map above)
  - Milestone name: `text-white font-semibold text-sm`
  - Milestone progress: `text-gray-500 text-xs` — e.g. `3/5 features`
  - Progress bar: same indigo-500 style as ProjectCard, `h-1.5 w-24`
- Feature row (indented 16px left): `flex items-center gap-3 py-2 pl-4`
  - Status dot (6px)
  - Feature name: `text-gray-300 text-sm`
  - Pipeline progress: `text-gray-500 text-xs` — e.g. `4/6 phases`
  - Mini phase pip row: 6 dots, filled indigo if complete, `bg-white/20` if not

### Tasks Tab — Grouped by Type

- Group header: `text-xs font-semibold text-gray-400 uppercase tracking-wider mb-2 mt-6`
- Group types in display order: decision, research, review, validation, skills
- Empty group: omit entirely (do not render header if no tasks of that type)
- Task card: reuse `TaskList` human variant (`bg-[#242424] border border-amber-500/20 rounded-lg p-4`)
- Added field vs current TaskList: linked feature name shown as `text-gray-500 text-xs font-mono` below task description

### Home Page — ProjectCard Extension

- Milestone progress replaces or sits below the existing phase progress bar
- Layout addition inside card, below current progress bar section:
  ```
  [milestone name truncated]    [N/M milestones]
  [progress bar — indigo-500]
  ```
- Feature count: `text-gray-500 text-xs` — `N features complete / M total`
- Needs Attention badge: `bg-red-500/15 text-red-400 border border-red-500/30 px-2 py-0.5 rounded-full text-xs` — only shown if project has blocked features or exceeded WIP limit
- Sparkline: 48px tall, 96px wide, Chart.js Line, no axes, no labels — cost trend only; color `rgb(99, 102, 241)` (indigo-500), tension 0.4

## Interaction Contracts

| Interaction | Behavior |
|-------------|----------|
| Tab click | Updates URL query param (`?tab=plan`), re-renders server content, no full page reload (Next.js Link or router.push) |
| Default tab on project page load | `?tab=metrics` — preserves v3.0 behavior for existing users |
| ProjectCard click | Navigates to `/project/[name]?tab=metrics` (existing behavior unchanged) |
| Feature row | Non-interactive — display only; no expand/collapse in this phase |
| Milestone row | Non-interactive — display only |
| Human task card | Non-interactive — display only; no inline complete action |
| Sparkline | Non-interactive — no tooltip, no hover state; pure visual indicator |
| Needs Attention badge | Non-interactive — visual signal only |

Loading states: each tab section renders a `<section>` skeleton using `bg-white/5 animate-pulse rounded-xl h-32` while server data loads. One skeleton per major panel.

Error boundaries: each tab content area wraps in a Next.js error boundary (`error.tsx` per route segment) with the error state copy defined above.

## Accessibility

- Tab bar: `role="tablist"`, each tab `role="tab"`, `aria-selected`, `aria-controls` pointing to tab panel
- Tab panels: `role="tabpanel"`, `id` matching tab `aria-controls`
- Status dots: `aria-label="{status}"` on dot element; not conveyed by color alone
- Progress bars: `role="progressbar"`, `aria-valuenow`, `aria-valuemin="0"`, `aria-valuemax="100"`
- Needs Attention badge: `aria-label="This project needs attention"` on badge container
- Sparkline canvas: `aria-hidden="true"` (decorative; cost trend also shown as text in card)
