Create `~/.claude/plugins/seraphim/lib/multi-project-scanner.js` (CommonJS, 'use strict').

Export one function: `discoverSeraphimProjects(roots)`.
- `roots` defaults to `[path.join(os.homedir(), 'projects'), path.join(os.homedir(), 'agent')]` when called with no arguments.
- For each root: if it does not exist, skip silently.
- Read each direct subdirectory of the root. For each directory, check if `{dir}/.seraphim/` exists. If yes, push the full project path to results.
- Return an array of absolute project root paths (not just names).
- Never throw — any error caught per-root logs to console.error and continues.

Also export `readProjectMeta(projectRoot)` — reads `.seraphim/config.json` (returns {} on missing/error), reads the last 200 lines of `.seraphim/decisions.jsonl` to compute `total_cost_usd` (sum of cost_usd for non-recommendation records), and returns:
```javascript
{
  project_name: config.project_name || path.basename(projectRoot),
  profile: config.profile || 'unknown',
  root_path: projectRoot,
  total_cost_usd: Number,
  last_activity: ISO string of most recent decision timestamp or null
}
```

Empty state: if discoverSeraphimProjects returns [], that is valid — callers render empty state messaging.

**progress-extractor.js** (CommonJS, 'use strict'):

Export `extractProgress(projectRoot)`.
- `PHASES = ['discover','envision','judge','architect','forge','crucible']`
- For each phase, check `.seraphim/phases/{phase}/state.json`. Parse if exists, skip if not.
- Count `completed` (where `state.completed === true`) and `total` (6).
- For blueprint.md task counting: check `.seraphim/phases/architect/blueprint.md`. Count `<!-- TASK:` or `SERAPHIM:TASK` marker occurrences for `tasks_total`. Count keys in `state.retries` across all phases for `tasks_done`.
- Return `{completed, total, tasks_done, tasks_total, current_phase}` where `current_phase` is the first phase whose `state.completed !== true` (or `'complete'` if all six done).
- Never throw — return `{completed:0, total:6, tasks_done:0, tasks_total:0, current_phase:'discover'}` on any error.

**push-client.js** (CommonJS, 'use strict'):

Export `pushProjectData(projectRoot, phaseId)`:
1. Read `.seraphim/config.json` (catch → {}).
2. Read ALL lines of `.seraphim/decisions.jsonl` (catch → []).
3. Read `.seraphim/phases/{phaseId}/state.json` (catch → {}).
4. Filter decisions: exclude `type === 'recommendation'` and `type === 'recommendation_response'`.
5. Build payload:
```javascript
{
  project_name: config.project_name || path.basename(projectRoot),
  root_path: projectRoot,
  profile: config.profile,
  phase_id: phaseId,
  phase_state: phaseState,
  decisions: filteredDecisions,
  pushed_at: new Date().toISOString()
}
```
6. Read `SERAPHIM_DASHBOARD_URL` and `SERAPHIM_DASHBOARD_SECRET` from `process.env`. If `SERAPHIM_DASHBOARD_URL` not set, write a warning to `~/.claude/plugins/seraphim/push-errors.log` and return early (do NOT throw).
7. POST to `${SERAPHIM_DASHBOARD_URL}/api/ingest` with headers `{ 'Content-Type': 'application/json', 'Authorization': 'Bearer ${SERAPHIM_DASHBOARD_SECRET}' }`.
8. Fire-and-forget: do NOT `await` at top level of the exported function. Chain `.catch(err => fs.appendFileSync(errorLog, ...))`. Never throw or reject — push hook must not block the pipeline (per Pitfall 3 in RESEARCH.md).
  </action>
