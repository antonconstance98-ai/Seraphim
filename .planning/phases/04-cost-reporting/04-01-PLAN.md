  <action>
Create `~/.claude/hooks/codex-cost-reporter.js` — a SessionStart hook that generates a Markdown cost report from the previous session's Codex activity.

**Script structure** (follow existing hook patterns — stdin JSON, stdout JSON, silent fail):

1. **Shebang and header**: `#!/usr/bin/env node` with `codex-hook-version: 1.0.0` comment. Add `'use strict';`. Require `fs`, `path`.

2. **Stdin handling**: Same timeout guard pattern as codex-token-logger.js — `setTimeout(() => process.exit(0), 10000)`. Read stdin JSON to get `session_id` and `cwd`.

3. **Load token log**: Read `{cwd}/.planning/token-log.jsonl`. If file does not exist or is empty, `process.exit(0)` silently (per D-07 — no report if no Codex activity).

4. **Parse all records**: Split file by newline, JSON.parse each line, skip malformed. Collect all valid records into an array.

5. **Session boundary detection** (Claude's discretion): Since SessionStart fires at the START of a new session and we want to report on the PRIOR session, use all records in the log. This works because:
   - The log accumulates across the project lifetime
   - The report summarizes ALL Codex activity to date for this project
   - The filename uses today's date so each day gets a fresh report
   - If multiple sessions per day, the report overwrites with cumulative data (per D-08 — append session count suffix if needed; for simplicity, overwrite with full cumulative view)

6. **Compute actual costs**: Sum `cost_usd` from all records. Also compute per-task-type breakdown by grouping records by `task_type` field and summing `cost_usd`, `tokens.input`, `tokens.cached_input`, `tokens.output` for each group (per D-03).

7. **Compute Opus-only baseline** (per D-04, D-09, D-10): For each record, re-compute cost as if `model` were `claude-opus-4-6`. Use Opus pricing: `{ input: 15.00, cached_input: 3.75, output: 75.00 }` per 1M tokens (current Anthropic pricing). Do NOT use `computeCost` from codex-exec.js for Opus since its PRICING table only has GPT models — define Opus pricing inline:
   ```javascript
   const OPUS_PRICING = { input: 15.00, cached_input: 3.75, output: 75.00 }; // per 1M tokens
   ```
   For each record, compute: `(tokens.input * 15.00 + tokens.cached_input * 3.75 + tokens.output * 75.00) / 1_000_000`

8. **Compute savings**: `savings = opusBaseline - actualCost`. `savingsPct = ((savings / opusBaseline) * 100).toFixed(1)`. Handle division by zero (opusBaseline === 0 means no tokens, should have exited at step 3).

9. **Generate Markdown report** (per D-01, D-02, D-03):

```markdown
# Codex Cost Report — {YYYY-MM-DD}

## Summary

| Metric | Value |
|--------|-------|
| Actual Codex Cost | ${actualCost.toFixed(4)} |
| Opus-Only Baseline | ${opusBaseline.toFixed(4)} |
| **Savings** | **${savings.toFixed(4)} ({savingsPct}%)** |
| Total Codex Calls | {recordCount} |

## Breakdown by Task Type

| Task Type | Calls | Tokens In | Tokens Out | Actual Cost | Opus Baseline |
|-----------|-------|-----------|------------|-------------|---------------|
| {taskType} | {count} | {tokensIn} | {tokensOut} | ${cost} | ${opusCost} |
| ... | ... | ... | ... | ... | ... |
| **Total** | **{total}** | **{totalIn}** | **{totalOut}** | **${totalActual}** | **${totalOpus}** |

## Model Comparison

| Model | Calls | Tokens | Cost |
|-------|-------|--------|------|
| gpt-5.4 | {n} | {tokens} | ${cost} |
| gpt-5.4-mini | {n} | {tokens} | ${cost} |

---
*Generated by codex-cost-reporter.js at {ISO timestamp}*
*Savings: Codex-routed tasks cost ${savings.toFixed(4)} less than running them through Opus alone.*
```

10. **Write report file** (per D-08, TRCK-04): Create `.planning/session-reports/` directory if it does not exist (`fs.mkdirSync recursive`). Write to `{cwd}/.planning/session-reports/{YYYY-MM-DD}.md`. Use `fs.writeFileSync`.

11. **Stdout output**: Write hook JSON response with `additionalContext` summarizing the report: `[Cost Report] Saved ${savings.toFixed(4)} ({savingsPct}%) vs Opus-only — report at .planning/session-reports/{date}.md`

12. **Error handling**: Wrap entire logic in try/catch. On any error, `process.exit(0)` silently — never block session start.

**Important**: The script must also work standalone when run directly with `node ~/.claude/hooks/codex-cost-reporter.js` (per D-06). Detect standalone mode: if stdin is a TTY (`process.stdin.isTTY === true`), use `process.cwd()` as cwd and skip stdin reading. Generate the report and print the output path to stderr.
