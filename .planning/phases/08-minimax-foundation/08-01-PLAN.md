    The script must:

    1. Read `~/.claude/dashboard/global.jsonl` line by line.
    2. For each valid JSON record that has a `tokens` field, recalculate `opus_baseline_usd` using the CORRECTED Opus 4.6 pricing: `{ input: 5.00, cached_input: 1.25, output: 25.00 }` per 1M tokens.
    3. The recalculation formula (matching `computeOpusCost` exactly):
       ```
       opus_baseline_usd = (tokens.input * 5.00 + tokens.cached_input * 1.25 + tokens.output * 25.00) / 1_000_000
       ```
       Note: NO rounding (matches `computeOpusCost` behavior — it does NOT call `toFixed`).
    4. Write updated content to a `.tmp.<pid>` file, then `fs.renameSync` to the original path (atomic write pattern from `codex-global-aggregator.js`).
    5. Print summary: records processed, records updated, old total opus_baseline vs new total.
    6. **Idempotency:** The script always recalculates from token counts, so running it multiple times produces identical results. There is no "already migrated" check needed — the output is deterministic.

    Script structure:
    ```javascript
    #!/usr/bin/env node
    // migrate-opus-pricing.js — One-time migration: recalculates opus_baseline_usd
    // in global.jsonl using corrected Opus 4.6 pricing ($5/$25 per Mtok).
    // Idempotent: always recalculates from stored token counts.
    // Safe: uses atomic write (temp-then-rename).

    'use strict';
    const fs = require('fs');
    const path = require('path');
    const os = require('os');

    const GLOBAL_JSONL = path.join(os.homedir(), '.claude', 'dashboard', 'global.jsonl');
    const NEW_OPUS = { input: 5.00, cached_input: 1.25, output: 25.00 };

    function recalcOpusBaseline(tokens) {
      const inp    = (tokens && tokens.input)        || 0;
      const cached = (tokens && tokens.cached_input)  || 0;
      const out    = (tokens && tokens.output)        || 0;
      return (inp * NEW_OPUS.input + cached * NEW_OPUS.cached_input + out * NEW_OPUS.output) / 1_000_000;
    }

    // ... read file, process each line, atomic rewrite, print summary
    ```
