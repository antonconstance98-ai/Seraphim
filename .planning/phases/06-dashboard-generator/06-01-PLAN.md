**3. `ensureChartJs()` function:**
- Creates `~/.claude/dashboard/assets/` directory with `fs.mkdirSync({ recursive: true })`
- If `CHART_JS_PATH` already exists AND file size > 100000 bytes, return early (already downloaded)
- Otherwise, use Node.js built-in `fetch()` (available on v22.22.0) to download from `CHART_JS_URL`
- Write the response body text to `CHART_JS_PATH`
- Wrap in try/catch — if download fails (no internet), log warning to stderr but do NOT throw. Chart.js is optional — tables still render without it.
- Return `true` if chart.min.js exists after the attempt, `false` otherwise.

- Group records by `project_name` to build projectTable. - Model split (DASH-03): group by `model`. Sum calls, token counts (input, cached_input, output separately), and cost.

```javascript
function generateDashboard(dashboardDir) {
  const dir = dashboardDir || DASHBOARD_DIR;
  const globalJsonl = path.join(dir, 'global.jsonl');
  if (!fs.existsSync(globalJsonl)) return null;
  const lines = fs.readFileSync(globalJsonl, 'utf8').trim().split('\n');
  const records = [];
  for (const line of lines) {
    if (!line.trim()) continue;
    try { records.push(JSON.parse(line)); } catch (e) { /* skip */ }
  }
  const data = computeMetrics(records);
  return data;
}
```
