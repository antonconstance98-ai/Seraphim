**2. `safeNum(value)` helper:**
Returns the value as a number if it is a finite number, otherwise returns 0. Used to guard against NaN, undefined, null, string, or Infinity values in cost_usd and opus_baseline_usd fields.
```javascript
function safeNum(v) { return (typeof v === 'number' && isFinite(v)) ? v : 0; }
```

**3. `htmlEscape(str)` function:**
Converts the input to a string first (handles numbers, booleans, null, undefined), then escapes `<`, `>`, `&`, `"`, `'`. Specifically:
- If input is `null` or `undefined`, return `''`
- Otherwise, call `String(input)` first, then replace the 5 HTML-special characters
- This means `htmlEscape(0)` returns `'0'`, not `''`
- This means `htmlEscape(false)` returns `'false'`, not `''`

**4. `ensureChartJs()` async function:**
- Creates `~/.claude/dashboard/assets/` directory with `fs.mkdirSync({ recursive: true })`
- If `CHART_JS_PATH` already exists: read the first 20 bytes of the file. If they start with `/*!` or `//` or `(function` (valid JS preamble), AND file size > 100000 bytes, return `true` (already downloaded and looks like valid JS, not an error page). If the file exists but fails this check, delete it and re-download.
- Otherwise, use Node.js built-in `fetch()` to download from `CHART_JS_URL`
- After download, validate: response must be `200 OK`, content-type should contain `javascript` or `application/`, and the response text should start with a valid JS preamble (not `<!DOCTYPE` or `<html` which indicates an error page)
- Write the validated response text to `CHART_JS_PATH`
- Wrap everything in try/catch — if download fails (no internet, CDN error, validation failure), log to stderr: `Dashboard: Chart.js download skipped (offline or CDN error)`, and return `false`. NEVER throw.
- Return `true` if a valid chart.min.js exists after the attempt, `false` otherwise.

**Implementation steps for computeMetrics:**

1. Filter valid records (must have string timestamp with length >= 10)
2. Initialize accumulators: totalCost=0, opusBaseline=0, reviewCount=0, blockCount=0
3. Initialize grouping Maps: byProject (Map), byModel (Map), bySession (Map), byTaskType (Map), unattributed accumulator
4. Single pass through valid records:
   - Accumulate totalCost += safeNum(r.cost_usd), opusBaseline += safeNum(r.opus_baseline_usd)
   - If task_type === 'review' AND verdict is non-empty string: reviewCount++; if verdict === 'BLOCK': blockCount++
   - Group by project_name: accumulate calls, cost, opusBaseline, reviewCount, blockCount, token sums (input, cached_input) for cache efficiency
   - Group by model: accumulate calls, token counts (input, cached_input, output), cost
   - Group by session_id (skip null): accumulate calls, cost, opusBaseline, reviews, blocks, collect records array, track max timestamp
   - Group by task_type: accumulate calls, cost
   - If session_id === null: accumulate into unattributed bucket (same fields as project row)
5. Build globalSummary from accumulators
6. Build projectTable: sort alphabetically by projectName, then append Unattributed row at the end (only if unattributed.calls > 0)
7. Build modelSplit: start with zeroed 'gpt-5.4' and 'gpt-5.4-mini' entries, then merge observed data. This ensures both models always appear.
8. Build blockLog: filter records where verdict === 'BLOCK' AND typeof block_summary === 'string' AND block_summary.trim().length > 0. Sort by timestamp descending (simple string comparison works for ISO 8601 format). Map to {timestamp, projectName, taskType, reviewTaskType, summary}.
9. Build sessionHistory: convert bySession Map to array, sort by maxTimestamp descending, take first 50. Map to the session entry shape.
10. Build taskTypeDistribution from byTaskType Map.
11. Return the DASHBOARD_DATA object.

**6. `generateDashboard(dashboardDir)` — working stub:**
This stub reads global.jsonl, parses records defensively, calls computeMetrics, and returns the data. Plan 02 will replace the stub body with full HTML rendering while keeping the same signature.

```javascript
function generateDashboard(dashboardDir) {
  const dir = dashboardDir || DASHBOARD_DIR;
  const globalJsonl = path.join(dir, 'global.jsonl');
  if (!fs.existsSync(globalJsonl)) return null;

  // Defensive JSONL parsing: skip blank lines and malformed JSON
  const raw = fs.readFileSync(globalJsonl, 'utf8');
  const records = [];
  for (const line of raw.split('\n')) {
    if (!line.trim()) continue;
    try { records.push(JSON.parse(line)); } catch (e) { /* skip malformed line */ }
  }
  if (records.length === 0) return null;

  const data = computeMetrics(records);
  return data;
}
```
