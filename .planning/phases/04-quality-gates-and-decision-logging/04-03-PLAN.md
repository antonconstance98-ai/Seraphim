## Step 3b — Detect Judge->Envision loop path (QUAL-03)

Check if judgment.md exists for this phase. If it does, parse it for the loop signal:

```bash
PLUGIN_ROOT="$HOME/.claude/plugins/seraphim"
node -e "
  const fs = require('fs');
  const path = require('path');
  const m = require('${PLUGIN_ROOT}/lib/markers');

  const judgmentPath = path.join('${PROJECT_ROOT}', '.seraphim', 'phases', '${PHASE_ID}', 'judgment.md');
  if (!fs.existsSync(judgmentPath)) {
    console.log(JSON.stringify({ loopRequired: false }));
    process.exit(0);
  }

  const content = fs.readFileSync(judgmentPath, 'utf8');
  const markers = m.parseMarkers(content);
  const phaseComplete = markers.find(mk => mk.type === 'PHASE_COMPLETE');
  const loopRequired = phaseComplete && phaseComplete.loop_required === 'true';

  let loopContext = '';
  if (loopRequired) {
    const fatalApproaches = markers.filter(mk => mk.type === 'APPROACH' && mk.verdict === 'FATAL_FLAW');
    if (fatalApproaches.length > 0) {
      const lines = ['## Previous Judge Findings', ''];
      lines.push('All approaches in the previous Envision run received FATAL_FLAW from Judge.');
      lines.push('You MUST generate approaches that address the following fatal flaws.');
      lines.push('Do NOT re-propose approaches with the same core design as any approach listed below.');
      lines.push('');
      fatalApproaches.forEach(a => {
        lines.push(\`### Approach \${a.id} — FATAL_FLAW\`);
        lines.push(\`**Reason:** \${a.reason || '(no reason recorded)'}\`);
        lines.push('');
      });
      loopContext = lines.join('\n');
    }
  }

  console.log(JSON.stringify({ loopRequired: !!loopRequired, loopContext }));
"
```

Capture the output and parse the JSON. If `loopRequired` is true:
- Print: "Judge->Envision loop detected. Injecting prior Judge findings into envision prompt."
- Store `loopContext` — it will be prepended to the envision prompt content in Step 6.

If `loopRequired` is false, continue normally (loopContext = '').
```
