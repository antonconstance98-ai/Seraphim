<objective>
Create centralized pricing module and refactor existing hooks to use it.

Purpose: Research (Pitfall F) identified that hardcoded pricing exists in two separate locations (codex-exec.js and codex-cost-reporter.js). Centralizing pricing before the dashboard consumes it gives the aggregator (Plan 02) a single source of truth for cost computations. This plan provides two computation functions: `computeCost` (backward-compatible, falls back to gpt-5.4 pricing for unknown models, matching current behavior) and `computeCodexCostStrict` (returns null for unknown models, used by the aggregator to surface pricing gaps visibly).

Output: `codex-pricing.js` shared module; refactored codex-exec.js and codex-cost-reporter.js to import from it.
</objective>
