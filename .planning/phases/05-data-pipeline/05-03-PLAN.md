<objective>
Close the 5 ms no-op run gap identified in 05-VERIFICATION.md.

Purpose: The ROADMAP success criterion requires a second consecutive run with no new data to complete in under 5 ms. The current implementation calls `discoverTokenLogs()` — which spawns 4 `spawnSync find` child processes — on every `aggregate()` invocation. This adds ~150 ms of child-process overhead regardless of whether any files have changed. Caching discovered paths in `project-index.json` and skipping `find` on warm runs reduces the no-op elapsed_ms to well under 5 ms.

Output: Modified `codex-global-aggregator.js` with a TTL-gated discovery cache. The `project-index.json` file gains a `discovered_files` array field that is written on every discovery run and read back on warm runs, eliminating the `find` spawns on consecutive calls.
</objective>

```javascript
/**
 * isCacheWarm() -- true if project-index.json exists and was written < TTL ago.
 * When warm, skip spawnSync find and use cached discovered_files instead.
 */
function isCacheWarm() {
  try {
    const stat = fs.statSync(INDEX_PATH);
    return (Date.now() - stat.mtimeMs) < DISCOVERY_CACHE_TTL_MS;
  } catch (e) {
    return false; // Missing or unreadable = cold
  }
}

/**
 * loadDiscoveryCache() -- read discovered_files from project-index.json.
 * Returns Array<{ filePath, projectPath, projectName }> or [] on failure.
 */
function loadDiscoveryCache() {
  try {
    const raw = fs.readFileSync(INDEX_PATH, 'utf8');
    const data = JSON.parse(raw);
    if (Array.isArray(data.discovered_files)) {
      return data.discovered_files;
    }
  } catch (e) {
    // Fall through
  }
  return [];
}
```
