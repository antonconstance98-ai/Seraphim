**File header:**
```javascript
#!/usr/bin/env node
// codex-hook-version: 1.0.0
// Global Aggregator — SessionStart hook (wired in Phase 7)
// Discovers all per-project token-log.jsonl files, deduplicates records,
// and incrementally merges them into ~/.claude/dashboard/global.jsonl.
//
// Dual-mode: works as SessionStart hook (stdin JSON) and standalone (TTY detection).
// Silent fail: any error calls process.exit(0) — never blocks session start.
//
// Required by: PIPE-01 (global merge), PIPE-02 (configurable roots),
//              PIPE-03 (mtime-gated incremental), PIPE-04 (null session_id as unattributed)
```

**1. Constants and requires:**
```javascript
'use strict';
const fs   = require('fs');
```

**3. Project discovery:**

For each root, use `execSync` with `find`:
```javascript
const findCmd = `find "${root}" -maxdepth ${maxDepth} -name "token-log.jsonl" -not -path "*/.claude/worktrees/*" -not -path "*/node_modules/*" -not -path "*/.git/*" 2>/dev/null`;
```
Collect all discovered paths. Derive `project_path` as the directory two levels up from the JSONL file (strip `/.planning/token-log.jsonl`). Derive `project_name` from the last path segment of `project_path`.

**4. Deduplication (PIPE-01):**

On startup, read existing `global.jsonl` (if it exists) line by line. Build a `Set<string>` of dedup keys. The dedup key for each record is: `${record.session_id}|${record.timestamp}` — this handles null session_id because `null` stringifies to `"null"`, and the combination with millisecond-precise timestamp is unique.

**5. Incremental reads (PIPE-03):**

Load `cache.json` (if exists) which stores per-file state:
```json
{
  "/path/to/project/.planning/token-log.jsonl": {
    "mtime_ms": 1743548330644,
    "size": 4096,
    "byte_offset": 4096
  }
}
```

For each discovered file:
- `fs.statSync()` to get current mtime and size.
- If `mtime_ms` and `size` match cache entry: skip entirely (file unchanged).
- If `size` is greater than cached `byte_offset`: read only from `byte_offset` to end of file using `fs.createReadStream` with `start: byte_offset`. Parse only the new lines.
- If `size` is less than cached `byte_offset` (file was truncated/rotated): re-read entire file from offset 0.
- If no cache entry: read entire file from offset 0.

**6. Record enrichment and appending:**

For each new line parsed from a source file:
- Parse as JSON. Skip malformed lines silently.
- Compute dedup key `${rec.session_id}|${rec.timestamp}`.
- If key is in the seen `Set`: skip (already in global.jsonl).
- If new: enrich the record with two additional fields:
  - `project_path`: absolute path to the project root
  - `project_name`: last segment of project_path (e.g., `"Claude_X_Codex"`)
- Also add `opus_baseline_usd`: call `computeOpusCost(rec.tokens)` from codex-pricing.js to compute what this call would have cost on Opus. The `rec.tokens` shape from token-log.jsonl uses `{input, cached_input, output}` which matches `computeOpusCost`'s expected input.
- Append the enriched record as a JSON line to `global.jsonl` using `fs.appendFileSync`.
- Add the key to the seen `Set`.

**7. Null session_id handling (PIPE-04):**

Records with `session_id: null` must NOT be dropped. The dedup key handles them via `"null|timestamp"`. When enriching, do NOT modify `session_id` — leave it as `null` in global.jsonl. The dashboard generator (Phase 6) will handle grouping them as "Unattributed".

**9. Atomic writes:**

All JSON state files (`project-index.json`, `cache.json`, `last-run.json`) must use write-then-rename:
```javascript
function atomicWriteJSON(filePath, data) {
  const tmp = filePath + '.tmp.' + process.pid;
  fs.writeFileSync(tmp, JSON.stringify(data, null, 2) + '\n', 'utf8');
  fs.renameSync(tmp, filePath);
}
```

**10. Dual-mode entry point:**

Same pattern as codex-cost-reporter.js:
- If `process.stdin.isTTY` (standalone mode): call `aggregate(process.cwd())` directly, print summary to stdout.
- If not TTY (hook mode): read stdin JSON, parse `cwd` from it, call `aggregate(cwd)`, output `{ additionalContext: "..." }` to stdout.

Use the established timeout guard: `setTimeout(() => process.exit(0), 10000)` for hook mode.

Wrap entire execution in try/catch with `process.exit(0)` on error (silent fail pattern).
