**app/api/planning/route.ts** (per D-04, D-07):
- `export const dynamic = 'force-dynamic';`
- Import `fs` and `path` from Node.js builtins, `NextResponse` from `next/server`
- Resolve planning dir: `const planningDir = process.env.PLANNING_DIR ?? path.join(process.cwd(), '../../.planning');`
- If planningDir does not exist, return `NextResponse.json({ phases: [], error: 'PLANNING_DIR not found' })`
- Read all subdirectories in `{planningDir}/phases/` using `fs.readdirSync`
- For each phase directory:
  - Count files matching `*-PLAN.md` pattern (plans total)
  - Count files matching `*-SUMMARY.md` pattern (plans complete)
  - Compute percent: `Math.round((summaries / plans) * 100)` or 0 if no plans
  - Extract phase name from directory name (strip leading number and dash)
  - Read each PLAN.md's frontmatter to extract `wave:` field — group plans by wave number
  - For each wave: count plans in wave, count which have corresponding SUMMARY.md
- Return JSON: `{ phases: [{ name, slug, plans, summaries, percent, waves: [{ wave, plans, complete }] }], milestone: { total_phases, completed_phases, percent } }`

**app/api/velocity/route.ts** (per D-05):
- `export const dynamic = 'force-dynamic';`
- Do NOT use `export const runtime = 'edge'` — must be Node.js runtime (per Pitfall 5)
- Import `execSync` from `child_process`, `NextResponse` from `next/server`
- Derive git root: `const gitRoot = path.dirname(process.env.PLANNING_DIR ?? path.join(process.cwd(), '../../.planning'));`
- Execute: `git log --oneline --since="7 days ago" --format="%ad" --date=short` in the git root directory
- Parse output: split by newline, count occurrences per date using a Map
- Sort by date ascending
- Return JSON: `{ velocity: [{ date: "2026-04-10", commits: 5 }, ...] }`
- If git command fails, return `{ velocity: [], error: 'Git not available' }`
