Create ~/.claude/plugins/seraphim/lib/pattern-analyzer.js as a 'use strict' CommonJS module.

Implement four exported functions using only Node.js built-ins (fs, path, crypto — no npm packages):

1. **loadDecisions(projectRoot)** — internal helper. Reads .seraphim/decisions.jsonl. Returns [] if file missing. Splits on newline, filters empty, parses JSON, filters null (parse failures). Does NOT filter by type — returns all records including recommendation records.

2. **aggregateDecisions(projectRoot)** — public export. Calls loadDecisions, then filters out records where record.type is 'recommendation' or 'recommendation_response'. Returns the filtered array.

3. **groupIntoRuns(records)** — public export. Uses the boundary pattern from RESEARCH.md: a 'discover' record that follows at least one prior record starts a new run. Input is execution records only (recommendation records already filtered). Returns array of arrays.

4. **computeRejectionRates(records)** — public export. Takes flat execution records (not grouped into runs). Groups by `${record.phase}::${record.model}`. A record is a failure if `record.outcome === 'failure' || record.loop_count > 0`. Confidence: n < 5 → 'LOW', 5 <= n < 20 → 'MEDIUM', n >= 20 → 'HIGH'. Returns sorted array by rejection_rate descending.

5. **computeProfileMetrics(runs)** — public export. Each run is an array of records. Profile = `run[0]?.profile || 'unknown'`. avg_cost = total cost_usd across all records in all runs for that profile / number of runs. For crucible_pass_rate: find the crucible phase record in each run; if it has quality_signals.crucible_pass_rate that is not null, include it in the average; if no runs have crucible data, avg_crucible_pass_rate = null.

module.exports = { aggregateDecisions, groupIntoRuns, computeRejectionRates, computeProfileMetrics };

Import decisions-logger.js for appendDecision. Import Node.js crypto for rec_id generation.

**RULES array** — define at top of file with two rules:
```javascript
const RULES = [
  {
    id: 'high-rejection-rate',
    test: (m) => m.rejection_rate >= 0.6 && m.n >= 3,
    message: (m) => `${m.model} in ${m.phase} rejected ${Math.round(m.rejection_rate * 100)}% of runs — consider switching to a higher-quality model for this phase`,
    confidence: (m) => m.confidence
  },
  {
    id: 'low-crucible-pass-rate',
    test: (m) => m.avg_crucible_pass_rate !== null && m.avg_crucible_pass_rate !== undefined && m.avg_crucible_pass_rate < 0.5 && m.n >= 3,
    message: (m) => `${m.profile || m.model} in ${m.phase || 'crucible'} Crucible pass rate is ${Math.round(m.avg_crucible_pass_rate * 100)}% — consider upgrading`,
    confidence: (m) => m.confidence || 'LOW'
  }
];
```

**rec_id generation** — `crypto.createHash('sha256').update(rule.id + phase + model + timestamp).digest('hex').slice(0, 8)`

**Deduplication** — before adding a recommendation, check existingRecords for any record where `r.type === 'recommendation' && r.rule_id === rule.id && r.phase === phase && r.model === model && r.status === 'pending'`. Only add if none found.

**appendRejection** — loads all records from decisions.jsonl (via fs.readFileSync + split + parse), finds the matching recommendation record by rec_id, uses its timestamp as original_recommendation_timestamp, then calls appendDecision with the response record.

module.exports = { generateRecommendations, appendRecommendations, appendRejection, RULES };
